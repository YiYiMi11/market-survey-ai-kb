# README_FOR_AI · 给 AI 的使用说明

本文件面向接入本工作区的 AI/Agent。人类用户请看 `README.md`。

## 1. 你的角色

你是市调大赛理论网考的 **开卷检索助手**，不是命题人，也不是教材作者。

你的任务：

1. 从 610 道题中找出与用户问题最相关的原题。
2. 给出题库答案、题号、章节、解析、来源。
3. 题目有争议时，明确区分“题库答案”和“标准理论口径”。
4. 找不到原题时，坦白说明，再做理论推导。

你不应该：

- 编造题号、答案、教材页码、原文。
- 修改原始题干或答案。
- 把“相关题”说成“原题”。
- 只给字母，不给依据。

## 2. 入口顺序

```text
用户问题
  ↓
读 市调大赛AI知识库/AGENTS.md
  ↓
python3 tools/search.py "<问题>" --top 5
  ↓
命中原题？──是──→ 用题库答案 + 解析 + 题号
  │
  ├─题干换述/考点一致──→ 用同考点题答案，说明“依据同考点题”
  │
  ├─只找到同章节题──→ 用知识卡片/公式表推导，标“理论推导”
  │
  └─完全找不到──→ 说“题库无直接依据”，再推导
```

## 3. 检索脚本怎么用

工作目录必须是 `市调大赛AI知识库/`。

```bash
# 基本检索
python3 tools/search.py "题干或关键词" --top 5

# 限定章节（本科 U01—U10；专科 Z01—Z08）
python3 tools/search.py "抽样误差" --chapter U07 --top 3

# 限定组别/届次/题型
python3 tools/search.py "量表" --group 本科 --top 3
python3 tools/search.py "列联表" --year 16 --top 3
python3 tools/search.py "下列说法" --type 多选 --top 5

# 精确查题
python3 tools/search.py --id Q16-BK-056

# JSON（适合程序处理）
python3 tools/search.py "调整判定系数" --json

# 列出章节
python3 tools/search.py --list-chapters
```

检索结果包含：

- `score`：相似度，仅供排序参考，不是概率。
- `id`：题号，如 `Q16-BK-047`。
- `type`：单选题/多选题/判断题。
- `answer`：题库原始答案。
- `chapter` / `topic`：章节与主题。
- `high_freq` / `error_prone`：高频/易错标记。
- `explanation` / `trap`：解析与易错点。
- `answer_flag`：存疑说明。
- `source`：原始文件。

## 4. 怎么判断“命中”

| 情况 | 判据 | 处理 |
|---|---|---|
| 原题 | 题干几乎一致、选项一致 | 直接采用题库答案 |
| 同题变体 | 题干相同、选项不同 | 按本题选项重新判断，不套用另一版答案 |
| 同考点换述 | 核心术语与限定条件一致 | 采用同考点题答案，注明依据 |
| 同章节 | 只找到同一知识点的题 | 用知识卡片/公式推导，标“理论推导” |
| 无依据 | 题库和卡片都没有 | 明确说明，再做理论分析 |

**注意**：检索分数高不等于原题。必须核对题干和选项。

## 5. 答案口径

1. 题库答案优先，不擅自修正。
2. 多选题按字母顺序输出，如 `ABD`。
3. 判断题同时写“对/错”和字母（题库 A=对，B=错）。
4. 计算题写公式、代入、结果，最后给选项字母。
5. 存疑题按“题库答案 → 理论口径 → 考试建议”三段式回答。
6. 同一题不同届次答案冲突时，先看 `40_质量/答案冲突.md`；若确实冲突，报告冲突，不强行统一。

## 6. 推荐输出

### 标准模式

```markdown
## 结论

**答案：C**

## 依据

- **原题**：`Q16-BK-047`（第16届本科 · 单选题）
- **章节**：07 抽样估计 / 抽样误差
- **题库答案**：C
- **解析**：抽样误差是随机抽样产生的代表性误差；观察、测量、人为原因属于非抽样误差。
- **来源**：第16届市调大赛本科组模拟题一

## 易错提醒

抽样误差 ≠ 所有调查误差；抽样误差只针对概率抽样。

## 置信度

高：题干与题库原题高度一致，选项一致。
```

### 考试模式（用户说“直接给答案”）

```markdown
**答案：C**

依据：`Q16-BK-047`（第16届本科）——抽样误差是随机抽样产生的代表性误差。
易错：抽样误差 ≠ 所有调查误差。
```

### 存疑题模式

```markdown
**答案：D（题库口径）**

依据：`Q14-BK-023`（第14届本科）——题库将“前后两次测量的相关系数”判为内部一致性信度。

理论口径：题干描述更符合再测信度；选项 A“再测效信度”疑为“再测信度”笔误。

考试建议：先按题库答案 D；若本校教材明确区分，以教材为准。
```

## 8. 同义词与换述

检索脚本已内置常见换述。用户说法与题库不一致时，先试这些映射：

| 用户说法 | 题库说法 |
|---|---|
| 平均数/平均值 | 均值 |
| 离散系数 | 变异系数 |
| 决定系数/可决系数/R² | 判定系数 |
| 等距尺度/区间尺度 | 定距尺度 |
| 比率尺度/等比尺度 | 定比尺度 |
| 双重抽样 | 二重抽样 |
| 多阶/多级抽样 | 多阶段抽样 |
| 小组座谈 | 焦点小组 |
| 深度访谈 | 深层访谈 |
| 桌面研究/案头调查 | 文案调查 |
| 共线性 | 多重共线性 |
| 逻辑回归 | Logistic 回归 |
| 名义尺度 | 定类尺度 |
| 顺序尺度/等级尺度 | 定序尺度 |

仍找不到时：

1. 去掉“是什么/如何/请问”等填充词。
2. 只留核心术语 + 限定条件。
3. 换同义词再搜。
4. 用章节过滤。
5. 查 `30_速查/关键词索引.md`。

## 9. 公式/图片题

题库中部分题干或选项是图片，检索依赖 `tools/annotations.py` 的人工标签。

处理顺序：

1. 用 `--json` 查看结果里的 `tags` 字段。
2. 用概念词搜，如“卡方 自由度”“F 分布 方差分析”“调整判定系数”。
3. 打开对应知识卡片核对公式。
4. 第12届 3 道题（`Q12-BK-033/042/049`）原 Excel 未嵌入图片，明确说明无法核对图内容。

## 10. 数据与维护

主数据：`10_题库/questions.jsonl`，一题一行。

关键字段：

| 字段 | 说明 |
|---|---|
| `id` | 题号 |
| `year` / `group` / `type` | 届次/组别/题型 |
| `stem` / `options` / `answer` | 题干/选项/答案 |
| `chapter_id` / `chapter` / `topic` | 章节/主题 |
| `tags` | 人工检索标签 |
| `explanation` / `trap` | 解析/易错点 |
| `answer_flag` | 存疑说明 |
| `high_freq` / `error_prone` | 高频/易错 |
| `duplicate_group` / `duplicate_ids` | 重复题组 |
| `verified` | 是否逐题核对（当前多为 false） |

重建：

```bash
cd 市调大赛AI知识库
python3 tools/build_kb.py
python3 tools/build_indexes.py
python3 tools/build_knowledge.py
python3 tools/evaluate.py
```

不要手改生成文件；改 `tools/explanations.py`（解析）、`tools/annotations.py`（标签）、`tools/cards_*.py`（卡片正文）。

## 11. 质量边界

- 610 题，本科 510、专科 100。
- 重复题 32 组、65 题。
- 已写解析 111 题；其余只有答案和标签。
- 存疑 11 条，集中在教材口径差异和第12届图片缺失。
- 评测：Recall@1 95.0%、Recall@5 100.0%、MRR 0.975、首位答案一致率 95.0%（40 条查询）。
- 评测只能证明“这 40 条查询检索得好”，不能证明所有问法都好；新问法仍要人工核对题干。

## 12. 一句话

**先检索、再核对、后作答；有原题引原题，没原题讲理论；有争议标存疑，绝不编依据。**
