# 公式表

> 用法：先看公式，再看“条件/陷阱”。考试中公式题通常只考一个点，不要整段推导。
> 符号：x̄ 样本均值，μ 总体均值，s 样本标准差，σ 总体标准差，n 样本量，N 总体规模，p 样本比例，π 总体比例，α 显著性水平，E 允许误差。

## 一、描述统计

| 指标 | 公式 | 条件/陷阱 |
|---|---|---|
| 算术平均数 | `x̄ = Σx / n` | 定距/定比；受极端值影响 |
| 加权平均数 | `x̄ = Σf·x / Σf` | 分组数据用组中值，结果是近似值 |
| 分组均值 | `x̄ ≈ Σf·M / Σf` | M 为组中值 |
| 中位数位置 | `(n+1)/2` | 先排序；偶数个取中间两值平均 |
| 分组中位数 | `Me = L + (n/2 - CF)/f · w` | L 下限，CF 累计频数，f 组频数，w 组距 |
| 众数 | 出现次数最多的值 | 定类数据也可用 |
| 分组众数 | `Mo = L + (f1-f0)/(2f1-f0-f2) · w` | f1 众数组频数，f0 前一组，f2 后一组 |
| 极差 | `R = max - min` | 只受两端值影响 |
| 四分位距 | `IQR = Q3 - Q1` | 稳健离散指标 |
| 样本方差 | `s² = Σ(x-x̄)²/(n-1)` | 分母 n-1，无偏估计 |
| 总体方差 | `σ² = Σ(x-μ)²/N` | 分母 N |
| 样本标准差 | `s = √s²` | 与原数据同单位 |
| 变异系数 | `CV = s/x̄ × 100%` | 无量纲；均值接近 0 时不稳定 |
| 标准分数 | `z = (x-x̄)/s` | 均值 0、标准差 1 |
| 偏态系数 | 三阶中心矩/σ³ | >0 右偏，<0 左偏 |
| 峰度 | 四阶中心矩/σ⁴ | 正态原始峰度=3，超额峰度=0 |

偏态经验关系：

```text
右偏（正偏）：均值 > 中位数 > 众数
左偏（负偏）：均值 < 中位数 < 众数
对称：均值 ≈ 中位数 ≈ 众数
```

经验法则：

```text
±1σ ≈ 68%
±2σ ≈ 95%
±3σ ≈ 99.7%
```

## 二、概率基础

| 公式 | 说明 |
|---|---|
| `P(A∪B) = P(A)+P(B)-P(A∩B)` | 加法公式 |
| `P(A∩B) = P(A)P(B|A)` | 乘法公式 |
| `P(B|A) = P(A∩B)/P(A)` | 条件概率 |
| `P(A|B) = P(B|A)P(A)/P(B)` | 贝叶斯公式 |
| `P(B) = ΣP(B|Ai)P(Ai)` | 全概率公式 |
| 二项分布均值 | `E(X)=np` |
| 二项分布方差 | `Var(X)=np(1-p)` |
| 正态标准化 | `z=(x-μ)/σ` |
| 样本均值分布 | `x̄ ~ N(μ, σ²/n)`（正态总体或大样本） |

## 三、参数估计

### 1. 总体均值

| 条件 | 置信区间 |
|---|---|
| σ 已知，正态总体或大样本 | `x̄ ± z_(α/2) · σ/√n` |
| σ 未知，正态总体 | `x̄ ± t_(α/2,n-1) · s/√n` |
| 有限总体无放回 | 标准误乘 `√(1-n/N)` |

### 2. 总体比例

```text
p ± z_(α/2) · √(p(1-p)/n)
```

条件：`np ≥ 5` 且 `n(1-p) ≥ 5`。

### 3. 总体方差

```text
[ (n-1)s² / χ²_(α/2,n-1) ,  (n-1)s² / χ²_(1-α/2,n-1) ]
```

条件：正态总体。

### 4. 样本量

| 估计对象 | 公式 | 说明 |
|---|---|---|
| 均值 | `n0 = (z·σ/E)²` | E 为允许误差 |
| 均值（有限总体） | `n = n0 / (1 + n0/N)` | 有放回/无限总体不修正 |
| 比例 | `n0 = z²·p(1-p)/E²` | p 未知取 0.5 |
| 考虑设计效应 | `n = deff · n0` | deff 见抽样部分 |
| 考虑回答率 | `n_final = n0 / 回答率` | 回答率越低，初始样本越大 |

> 陷阱：比例取 0.5，方差 p(1-p) 取 0.25。看清题目问“比例”还是“方差/变异程度”。

## 四、假设检验

### 1. 均值检验

| 情形 | 统计量 | 自由度 |
|---|---|---|
| 单样本，σ 已知 | `z=(x̄-μ0)/(σ/√n)` | — |
| 单样本，σ 未知 | `t=(x̄-μ0)/(s/√n)` | n-1 |
| 两独立样本，方差齐 | `t=(x̄1-x̄2)/√(sp²(1/n1+1/n2))` | n1+n2-2 |
| 两独立样本，方差不齐 | `t=(x̄1-x̄2)/√(s1²/n1+s2²/n2)` | Welch 近似 |
| 配对样本 | `t=d̄/(s_d/√n)` | n-1 |

其中：

```text
sp² = [(n1-1)s1² + (n2-1)s2²] / (n1+n2-2)
```

### 2. 比例检验

```text
z = (p - π0) / √(π0(1-π0)/n)
```

### 3. 方差检验

| 情形 | 统计量 | 自由度 |
|---|---|---|
| 一个总体方差 | `χ²=(n-1)s²/σ0²` | n-1 |
| 两个总体方差比 | `F=s1²/s2²` | (n1-1, n2-1) |

### 4. 列联表检验

```text
χ² = Σ (O-E)²/E
E_ij = (行合计×列合计)/总合计
df = (r-1)(c-1)
```

### 5. 两类错误

| 决策 | H0 真 | H0 假 |
|---|---|---|
| 拒绝 H0 | 第一类错误 α | 正确（功效 1-β） |
| 不拒绝 H0 | 正确 | 第二类错误 β |

> 样本量增大，标准误减小，两类错误通常都减小，功效提高。

## 五、抽样设计

### 1. 简单随机抽样

```text
均值：ȳ = Σy/n
方差：V(ȳ) = (1-f)·S²/n
标准误：SE(ȳ) = √[(1-f)·S²/n]
比例：V(p) ≈ (1-f)·p(1-p)/n
```

其中 `f=n/N` 为抽样比，`(1-f)` 为有限总体修正因子。

### 2. 分层抽样

```text
层权：W_h = N_h/N
估计量：ȳ_st = Σ W_h·ȳ_h
方差：V(ȳ_st) = Σ W_h²·(1-f_h)·S_h²/n_h
```

样本量分配：

```text
比例分配：n_h = n·N_h/N
奈曼分配：n_h = n·N_h·S_h / Σ(N_h·S_h)
最优分配：n_h ∝ N_h·S_h/√c_h
```

### 3. 设计效应

```text
deff = V(设计) / V(简单随机)
```

| deff | 含义 |
|---|---|
| =1 | 与简单随机相同 |
| <1 | 效率更高（分层） |
| >1 | 效率更低（整群、多阶段） |

整群抽样近似：

```text
deff ≈ 1 + (m-1)·ρ
```

m 为群规模，ρ 为群内相关系数。

### 4. 样本量与回答率

```text
考虑设计效应：n = deff·n0
考虑回答率：n_final = n0/回答率
无回答调整因子 = 原样本权数之和 / 回答单元权数之和
设计权数 = 1/入样概率
```

### 5. 比率估计与回归估计

```text
比率估计：R̂ = ȳ/x̄，Ŷ = R̂·X
回归估计：ȳ_lr = ȳ + b(X - x̄)
```

比率估计是回归估计的特例。

## 六、相关与回归

### 1. 相关系数

```text
r = Cov(X,Y)/(s_X·s_Y)
r = [nΣxy - ΣxΣy] / √{[nΣx²-(Σx)²][nΣy²-(Σy)²]}
```

- `-1 ≤ r ≤ 1`
- r>0 正相关，r<0 负相关，r=0 线性无关
- 显著性检验：`t = r√(n-2)/√(1-r²)`，df=n-2

Spearman 秩相关：对秩次计算 Pearson 相关。

### 2. 一元线性回归

```text
模型：Y = a + bX + ε
b = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²
a = ȳ - b·x̄
```

### 3. 判定系数与估计标准误差

```text
SST = SSR + SSE
R² = SSR/SST = 1 - SSE/SST
Se = √(SSE/(n-2))
```

- R² 表示回归解释的变异比例。
- R² 开方只给 |r|，符号看 b。
- 一元回归误差方差无偏估计：`σ̂² = SSE/(n-2)`。

### 4. 回归系数检验

```text
t = b/Sb，df = n-2
F = MSR/MSE = (SSR/1)/(SSE/(n-2))
```

一元回归中，t 检验、F 检验、相关系数检验等价。

### 5. 多元回归

```text
R²_adj = 1 - (1-R²)(n-1)/(n-k-1)
F = (SSR/k)/(SSE/(n-k-1))，df=(k,n-k-1)
VIF_j = 1/(1-R_j²)
```

- k 为自变量个数。
- VIF 越大，多重共线性越严重；VIF>10 通常严重。
- 调整 R² 会小于 R²，且可能为负。

### 6. DW 统计量

```text
DW = Σ(e_t - e_(t-1))² / Σe_t²
```

| DW | 含义 |
|---|---|
| ≈2 | 无一阶自相关 |
| ≈0 | 正自相关 |
| ≈4 | 负自相关 |

### 7. Logistic 回归

```text
logit(p) = ln[p/(1-p)] = β0 + β1X1 + ... + βkXk
p = 1/(1+e^(-(β0+ΣβjXj)))
odds = p/(1-p)
OR = e^β
```

- OR>1：事件发生优势增加。
- OR<1：事件发生优势降低。
- OR=1：无影响。
- Wald 检验：单个系数显著。
- 似然比/Score 检验：模型整体显著。

### 8. 预测区间

```text
均值置信区间：ŷ0 ± t·Se·√(1/n + (x0-x̄)²/Σ(x-x̄)²)
个别值预测区间：ŷ0 ± t·Se·√(1 + 1/n + (x0-x̄)²/Σ(x-x̄)²)
```

个别值预测区间比均值置信区间更宽。

## 七、多变量分析

### 1. 因子分析

```text
X_i = a_i1F1 + a_i2F2 + ... + a_imFm + ε_i
共同度：h_i² = Σa_ij²
特殊方差：ψ_i = 1 - h_i²
```

- 因子载荷 a_ij 是变量 i 与因子 j 的相关系数。
- 共同度 + 特殊方差 = 1。
- KMO 越大越适合因子分析（一般 >0.6 可接受）。
- Bartlett 球形检验显著（p<0.05）才适合因子分析。

### 2. 聚类分析

```text
欧氏距离：d(x,y) = √Σ(x_i-y_i)²
K 均值目标：最小化 Σ Σ ||x - μ_k||²
```

- 系统聚类：层次合并，树状图。
- K 均值：快速聚类，需指定 K，适合大样本连续变量。
- 聚类前通常需要标准化，消除量纲。

### 3. 对应分析

```text
行轮廓 = 行频数/行合计
列轮廓 = 列频数/列合计
卡方距离、惯量、行列得分
```

- 输入列联表。
- 输出行列联合图。
- 小样本结果不稳定。

### 4. 多维标度

```text
输入：相似性矩阵/距离矩阵
输出：低维坐标、Stress 压力系数
```

Stress 越小，拟合越好。

### 5. 联合分析

```text
属性效用范围 = 最大效用 - 最小效用
```

例：-3.79、2.57、0.18 → 2.57-(-3.79)=6.36。

### 6. 综合评价

```text
综合得分 = Σ w_j · z_ij
```

- z_ij 为无量纲化后的指标值。
- w_j 为权重，Σw_j=1。
- 无量纲化：标准化、归一化、功效系数、指数化。
- 权重：主观赋权（德尔菲、AHP）、客观赋权（主成分、因子、熵权）。

## 八、时间序列与统计指数

### 1. 增长与速度

```text
环比增长速度 = (本期-上期)/上期
定基增长速度 = (本期-基期)/基期
两年共增长 = (1+r1)(1+r2)-1
平均增长速度 = (末期/初期)^(1/n)-1
```

例：3% 和 4% → `1.03×1.04-1=7.12%`。

### 2. 季节指数

```text
季节指数 = 各期平均值 / 总平均值 × 100%
```

- 无季节变动时，季节指数=100%（或 1）。
- 各期季节指数之和应约为 400%（季度）或 1200%（月度）。

### 3. 统计指数

```text
拉氏价格指数 = Σp1q0 / Σp0q0
帕氏价格指数 = Σp1q1 / Σp0q1
销售额指数 = 价格指数 × 销售量指数
```

## 九、公式使用检查清单

1. **看清对象**：总体还是样本？均值、比例还是方差？
2. **看清条件**：σ 已知还是未知？大样本还是小样本？正态还是非正态？
3. **看清方向**：双侧、右侧还是左侧？
4. **看清分母**：样本方差 n-1；一元回归误差方差 n-2；多元回归 n-k-1。
5. **看清单位**：标准差与原数据同单位；方差是平方单位；变异系数无量纲。
6. **看清口径**：比例取 0.5，方差取 0.25；R² 开方只给 |r|。
7. **看清题目问法**：“区间宽度”与“置信度”同向；“精度”与“区间宽度”反向。
8. **看清样本量**：总体规模通常不直接进入简单随机抽样样本量公式。
9. **看清显著性**：统计显著不等于实际重要；相关不等于因果。
10. **看清教材**：题库答案与教材表述冲突时，以本校教材/题库答案为准，并在答题时说明依据。
