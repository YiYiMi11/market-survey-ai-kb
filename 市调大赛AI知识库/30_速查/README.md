## 五、推荐使用顺序

### 开卷考试中

1. 用 `tools/search.py "<题干关键词>"` 或 `题干索引.md` 找原题。
2. 看题号、答案、章节。
3. 若题目涉及概念辨析/公式，打开 `易混概念.md` 或 `公式表.md` 核对。
4. 若题目被标“待核对”，看 `40_质量/答案存疑.md`，按“题库答案 → 理论口径 → 教材优先”回答。

### 平时复习

1. 先看 `高频考点.md`，圈出反复考的章节。
2. 读对应 `20_知识/` 卡片。
3. 做 `高频题解析.md` + `易错题解析.md`。
4. 用 `判断题陷阱.md`、`多选题清单.md` 查漏。
5. 最后用 `50_评测/基准问题.md` 自测检索。

## 六、注意

- 速查文件都是自动生成或从主数据派生，**不要直接改**；改 `tools/` 下的源文件后重跑构建。
- 题号格式：`Q<届>-<组别>-<序号>`，如 `Q16-BK-047`、`Q17-ZK-033`。
- `★` 表示高频重复题，`⚠` 表示已写解析的易错题。
- 题库答案优先；教材口径不同时，以本校教材为准，并说明依据。
