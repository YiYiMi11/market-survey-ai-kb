# AGENTS.md · 市调大赛 AI 知识库

本文件是本仓库的 Agent 入口。任何 AI/OpenCode 会话进入本项目，先读本文件，再按这里的检索流程答题。

## 0. 项目定位

- 面向 **全国大学生市场调查与分析大赛（市调大赛）理论网考**。
- 主要面向 **本科组 + 第17届提纲**；专科组题目作为补充完整保留。
- 题库覆盖第12—17届本科模拟题（510 题）和第17届专科模拟题（100 题），共 **610 题**。
- 用途：开卷考试时按题干检索相似题、给出答案与依据；也可用于复习和错题排查。
- 原则：**完整保留原题，不删题、不改题干、不改答案**。有疑点只做标注，不擅自修正。

## 2. 标准答题流程

### 第一步：理解题干

提取四类信息：

1. **题型**：单选、多选、判断。
2. **核心概念**：如“抽样误差”“判定系数”“整群抽样”。
3. **限定条件**：如“σ 已知”“样本量不变”“总体差异大”“错误的是”。
4. **选项差异**：特别注意“正确的是/错误的是”“属于/不属于”“最高/最低”。

### 第二步：检索原题

优先用检索脚本：

```bash
cd 市调大赛AI知识库
python3 tools/search.py "<题干或关键词>" --top 5
```

可加过滤：

```bash
python3 tools/search.py "抽样误差" --chapter U07 --top 3
python3 tools/search.py "量表 绝对零点" --group 本科 --top 3
python3 tools/search.py "列联表 自由度" --json
```

### 第三步：判断是否命中

| 情况 | 处理 |
|---|---|
| 题干几乎一致、选项一致 | 直接采用题库答案 |
| 题干一致但选项不同 | 不要套用答案；按本题选项重新判断，必要时看重复题组说明 |
| 题干换述但考点一致 | 采用题库答案，并说明“依据同考点题” |
| 只找到同章节题 | 用知识卡片和公式推导，标记“理论推导” |
| 完全找不到 | 明确说“题库无直接依据”，再给理论分析；不要假装有原题 |

### 第四步：核对疑点

- 看 `answer_flag` 字段或 `40_质量/答案存疑.md`。
- 如果题目被标记存疑，回答时要写清“题库答案是 X；按标准理论可能是 Y；考试建议以本校教材为准”。
- 图片题如果图片缺失（第12届 3 题），要说明“原题图片未嵌入，无法核对图内容”。

### 第五步：输出

默认用下面的格式，除非用户要求只要答案。

```markdown
## 结论

**答案：C**

## 依据

- **原题**：`Q16-BK-047`（第16届本科 · 单选题）
- **章节**：07 抽样估计 / 抽样误差
- **题库答案**：C
- **解析**：抽样误差是随机抽样产生的代表性误差；观察、测量、人为原因属于非抽样误差。
- **来源**：`第12-16届网考相关资料/第16届市调大赛本科组模拟题一(1).docx`

## 易错提醒

不要把“抽样误差”理解成所有调查误差；抽样误差只针对概率抽样。

## 置信度

高：题干与题库原题高度一致，选项一致。
```

### 考试模式（用户说“直接给答案/开卷考试”）

压缩为：

```markdown
**答案：C**

依据：`Q16-BK-047`（第16届本科）——抽样误差是随机抽样产生的代表性误差。
易错：抽样误差 ≠ 所有调查误差。
```

仍然要保留题号依据，不能只给字母。

## 3. 引用规范

1. 每题必须引用 `id`，格式 `` `Q16-BK-047` ``。
2. 引用解析时，说明是“题库解析”还是“理论推导”。
3. 引用知识卡片时，写章节名，如“见 `20_知识/本科/07_抽样估计.md`”。
4. 不要编造题号、届次、页码、教材原文。
5. 不确定教材页码时，只写章节和知识点，不写页码。
6. 如果用户要求“出处”，优先给：题号 → 原始文件 → 章节卡片；不要给不存在的链接。

## 4. 答案口径规则

- **原题答案优先**：题库保留原始答案，Agent 不擅自改动。
- **同题干不同选项**：按本题选项重新判断，不能直接套用另一版的答案。
- **答案冲突**：先看 `40_质量/答案冲突.md`；若同一题同一选项答案不同，报告冲突。
- **存疑题**：先给题库答案，再给理论口径，最后给考试建议。
- **多选题**：按字母顺序输出，如 `ABD`；不要漏选、不要多选。
- **判断题**：原题库用 A=对、B=错；输出时同时写“对/错”和字母，避免歧义。
- **计算题**：写出公式、代入、结果；如果题目只问选项，最后给字母。

## 5. 检索策略细节

### 5.1 关键词优先级

1. 题干中的专业术语（如“判定系数”“整群抽样”）。
2. 题干中的限定词（如“σ 未知”“样本量不变”）。
3. 选项中的差异词（如“方差相等”“完全相关”）。
4. 章节名/主题名。

### 5.2 换述处理

常见换述：

| 题干说法 | 题库说法 |
|---|---|
| 平均数 | 均值 |
| 离散系数 | 变异系数 |
| 决定系数 | 判定系数 |
| 等距尺度 | 定距尺度 |
| 比率尺度 | 定比尺度 |
| 双重抽样 | 二重抽样 |
| 多阶抽样 | 多阶段抽样 |
| 小组座谈 | 焦点小组 |
| 深度访谈 | 深层访谈 |
| 桌面研究 | 文案调查 |
| 共线性 | 多重共线性 |
| 逻辑回归 | Logistic 回归 |

`tools/search.py` 已内置同义词归一；仍找不到时，手动换词再搜。

### 5.3 公式图片题

部分题干/选项是图片（如 χ²、F 分布、判定系数公式）。处理顺序：

1. 用 `--json` 看 `tags` 字段（如“卡方分布”“F分布”“调整判定系数”）。
2. 用关键词搜，如“卡方 自由度”“F 分布 方差分析”。
3. 打开对应知识卡片核对公式。
4. 如果图片缺失，明确说明无法核对图内容。

## 6. 无依据时怎么办

如果题库、知识卡片、公式表都没有直接依据：

1. 明确说：“题库中没有直接对应的题；以下是基于统计理论的推导。”
2. 给出推导过程和结论。
3. 标注“理论推导，非题库原答案”。
4. 如果涉及教材口径争议，建议用户以本校教材为准。
5. **禁止**编造题号、答案、教材页码来制造依据。

## 7. 维护规则

改题库或加题时：

```bash
cd 市调大赛AI知识库
python3 tools/build_kb.py       # 重新解析原始 docx/xlsx，生成题库与质量报告
python3 tools/build_indexes.py  # 重新生成速查索引、统计、解析
python3 tools/build_knowledge.py # 重新生成知识卡片与本章题目索引
python3 tools/search.py "测试"  # 冒烟测试
```

注意：

- `build_kb.py` 会重新生成 `questions.jsonl/csv`、按届/按章节 Markdown、质量报告。
- `explanations.py` 存高频/易错解析；改解析改这里，不要直接改生成文件。
- `annotations.py` 存检索标签；公式图片题、换述题优先在这里补标签。
- `build_knowledge.py` 只重新生成 `20_知识/`；卡片正文在 `cards_*.py`。
- 不要手动改 `questions.jsonl` 后再跑 `build_kb.py`，否则会被覆盖；要改就改解析脚本或原始文件。

## 8. 数据字段说明

`questions.jsonl` 主要字段：

| 字段 | 含义 |
|---|---|
| `id` | 题目 ID，如 `Q16-BK-047` |
| `year` | 届次 |
| `group` | 本科/专科 |
| `type` | 单选题/多选题/判断题 |
| `stem` | 题干（可能含 `[[IMG:...]]`） |
| `options` | 选项字典 |
| `answer` | 原始答案字母 |
| `chapter_id` | 章节 ID |
| `chapter` | 章节名 |
| `topic` | 主题 |
| `keywords` | 自动/规则关键词 |
| `tags` | 人工语义标签（公式图片题、换述题） |
| `high_freq` | 是否重复题组成员 |
| `error_prone` | 是否已写易错解析 |
| `explanation` | 解析 |
| `trap` | 易错点 |
| `answer_flag` | 答案/图片存疑说明 |
| `duplicate_group` | 重复题组 ID |
| `duplicate_ids` | 同组其他题 ID |
| `reviewed` | 是否已人工写解析 |
| `verified` | 是否已逐题核对（当前多为 false） |

## 9. 质量与边界

- 题库答案来自原始模拟题，**未逐题对照教材核对**；`verified=false` 表示尚未逐题核验。
- 已写解析的题：高频 65 题、易错 46 题（有重叠）。
- 已知存疑：见 `40_质量/答案存疑.md`。
- 第12届 3 道题的图片是平台相对路径，源文件未嵌入，无法显示。
- 知识卡片是按第17届提纲和标准统计理论编写的，不替代教材；教材口径冲突时以本校教材为准。
- 不提供作弊性“代考”承诺；本知识库用于开卷检索和复习。

## 10. 一句话工作准则

**先检索原题，再给答案；有原题引原题，没原题讲理论；有争议标存疑，绝不编依据。**
