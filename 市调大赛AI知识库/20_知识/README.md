## 怎么用

1. 先按题干关键词在 `30_速查/关键词索引.md` 或 `tools/search.py` 找题。
2. 找到题目后，回到对应章节卡片核对概念边界和公式条件。
3. 卡片中的“待核对”表示教材口径可能有差异，考试时以本校教材为准。
