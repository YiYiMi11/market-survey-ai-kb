# Z05 调查实施与报告

> 对应第17届专科提纲第5章：市场调查的组织与实施；数据整理；调查数据的处理和汇总；报告撰写与演示。
> 本章题量 11，重点是“调查实施含义、统计表规范、报告结构、报告开头方式”。

## 一句话定位

调查实施是“把方案落到现场”；数据整理是“把原始资料变成可用数据”；报告是“把结果变成可读的结论”。

## 核心概念

### 1. 调查实施

- 定义：针对调查对象进行信息的收集（`Q17-ZK-044`）。
- 内容：调查员培训、现场访问、进度控制、质量复核、异常处理。
- 质量控制：陪访、回访、录音、逻辑校验、复核问卷。
- 调查员管理：统一培训、统一口径、监督评估。

### 2. 数据整理

1. 问卷接收与检查。
2. 审核：完整性、准确性、一致性。
3. 编码。
4. 录入。
5. 净化：缺失值、异常值、逻辑矛盾。
6. 分组汇总。
7. 制表/制图。

- 统计表的主词：所要说明的对象（`Q17-ZK-037`）。
- 统计表的宾词：说明总体的统计指标。
- 统计表规范：一个表说明一个要点、标题清楚简洁、计量单位明确、不能随意缩写标题（`Q17-ZK-043`）。
- 定量数据图形：直方图、折线图、散点图；直方图与条形图不同（`Q17-ZK-038`）。

### 3. 调查报告的结构

| 部分 | 内容 |
|---|---|
| 标题 | 被调查单位、调查内容、时间 |
| 目录 | 章节页码 |
| 摘要 | 目的、方法、主要发现、结论 |
| 正文 | 调查背景、调查对象与方法、调查结果、结论与建议 |
| 附录 | 问卷、统计表、原始数据、参考书目 |

> `Q17-ZK-034`：不包含在正文部分的是 **参考书目与附录**。
>
> `Q17-ZK-039`：主题包含不了但与主题有关、必须附加说明的部分叫 **附录**。
>
> `Q17-ZK-090`：书面报告不需要“按部就班完整表达全过程”，应突出重点 → 题干错。
>
> `Q17-ZK-088`：演示报告是书面报告的浓缩版本，包含主要观点和重要结论 → 对。
>
> `Q17-ZK-091`：书面报告一般通过标题把被调查单位、调查内容明确具体地表示出来 → 对。

### 4. 报告开头方式

| 开头方式 | 特点 |
|---|---|
| 开门见山，揭示主题 | 直接点明主题 |
| 结论先行，逐步论证 | 先写结论，再展开论证（`Q17-ZK-041`） |
| 交代情况，逐层分析 | 先背景，再分析 |
| 提出问题，引入正题 | 先设问，再回答 |

### 5. 无回答/代理回答

- 被调查者不在，但调查信息是“所有家庭成员都知道”的，可以由其他成员代理回答（`Q17-ZK-035`）。
- 如果信息只有本人知道，应另约回访，不能代理。

### 6. 报告撰写要求

- 客观、准确、简明、可读。
- 观点与数据统一。
- 结构清晰、重点突出。
- 图表规范、注释完整。
- 结论有依据，建议可操作。
- 不偏袒委托方，如实报告。

## 常考结论

1. 调查实施 = 针对调查对象收集信息。
2. 统计表主词 = 所要说明的对象；宾词 = 统计指标。
3. 统计表标题不能随意缩写。
4. 报告正文不包括参考书目与附录。
5. 附录 = 主题之外但必须附加说明的部分。
6. 结论先行、逐步论证是一种报告开头方式。
7. 演示报告是书面报告的浓缩版。
8. 书面报告不需要按部就班完整表达全过程。
9. 家庭成员都知道的信息，可由其他成员代理回答。

## 易混点

| A | B | 区别 |
|---|---|---|
| 主词 | 宾词 | 说明对象 vs 统计指标 |
| 正文 | 附录 | 核心内容 vs 补充材料 |
| 书面报告 | 演示报告 | 完整详细 vs 浓缩提炼 |
| 代理回答 | 更换被调查者 | 由知情成员代答 vs 换人 |
| 结论先行 | 开门见山 | 先结论后论证 vs 直接点题 |

## 答题套路

- 看到“调查实施”→ 收集信息。
- 看到“统计表主词”→ 所要说明的对象。
- 看到“报告正文不包括”→ 参考书目、附录。
- 看到“主题之外必须附加说明”→ 附录。
- 看到“先写结论再论证”→ 结论先行。
- 看到“演示报告”→ 书面报告浓缩版。
- 看到“家庭成员都知道的信息，本人不在”→ 代理回答。

## 待核对

- 统计表主词/宾词的定义在不同教材中表述略有差异，常见为主词=对象、宾词=指标。
- 报告开头方式的名称可能因教材不同而略有差异，按题干描述匹配。
