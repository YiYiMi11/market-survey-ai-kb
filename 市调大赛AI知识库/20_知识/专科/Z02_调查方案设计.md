# Z02 调查方案设计

> 对应第17届专科提纲第2章：调查的策划与调查方案的设计（不含抽样设计和问卷设计）。
> 本章题量 4，题少但常考“方案内容/方案评价/方案制定时点”。

## 一句话定位

调查方案是把调查目的转化为可执行计划的文件，规定“调查什么、调查谁、怎么调查、什么时候、花多少钱、谁来组织”。

## 核心概念

### 1. 调查方案的内容

| 部分 | 内容 |
|---|---|
| 调查背景与目的 | 为什么调查、要解决什么问题 |
| 调查对象与范围 | 调查谁、覆盖到哪里 |
| 调查内容 | 调查哪些变量、指标 |
| 调查方式方法 | 普查/抽样/重点/典型；访问/观察/实验/文案 |
| 调查时间与期限 | 资料所属时间、工作起止时间 |
| 调查进度 | 各阶段时间安排 |
| 调查预算 | 费用项目与金额 |
| 组织与人员 | 分工、培训、管理 |
| 质量控制 | 审核、回访、复核 |
| 报告形式 | 书面报告、演示报告 |

### 2. 调查目标的陈述

- 调查目标通常放在方案的 **引言/前言/背景部分**（`Q17-ZK-011` 答案 C）。
- 目标要具体、可测量、可操作，避免空泛。
- 调查目标决定调查内容、对象、方法和样本量。

### 3. 调查方案的评价

- 经验判断法：由专家/有经验人员根据经验评价方案的可行性、合理性（`Q17-ZK-008`）。
- 试点/预调查：小范围试验，检验方案可行性。
- 方案评估标准：目标明确、方法匹配、对象清楚、时间合理、预算可行、质量控制到位。

### 4. 调查方案的制定时点

- 调查方案应在调查实施 **之前** 制定，不能“调查过程中随时制定”（`Q17-ZK-079` 答案：错）。
- 方案可以根据预调查结果修改，但重大调整要有依据并记录。

### 5. 明确调查目的的意义

- 明确调查目的是调查方案设计的 **前提/起点**（`Q17-ZK-013` 答案 A）。
- 目的不清会导致：调查内容偏离、样本选择错误、问卷冗长、结论无法使用。

## 常考结论

1. 调查目标是方案设计的起点。
2. 调查目标陈述一般放在方案引言/背景部分。
3. 方案必须在调查实施前制定。
4. 经验判断是评价调查方案的方法之一。
5. 方案内容不包括具体的问卷题目设计（那是问卷设计阶段）。

## 易混点

| A | B | 区别 |
|---|---|---|
| 调查目的 | 调查目标 | 为什么调查 vs 具体达到什么结果 |
| 调查方案 | 调查问卷 | 全过程计划 vs 数据采集工具 |
| 调查时间 | 调查期限 | 资料所属时间 vs 工作起止时间 |
| 经验判断 | 预调查 | 专家凭经验评价 vs 小范围试调查 |

## 答题套路

- 看到“方案设计的起点/前提”→ 明确调查目的。
- 看到“调查目标陈述位置”→ 引言/背景。
- 看到“方案能否调查中随时制定”→ 错，必须事先制定。
- 看到“经验判断评价方案”→ 由有经验人员判断可行性。

## 待核对

- 调查目标在方案中的具体位置可能因模板不同而略有差异，常见为引言/前言/背景部分。
