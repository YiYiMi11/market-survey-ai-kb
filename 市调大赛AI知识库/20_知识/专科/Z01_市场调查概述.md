# Z01 市场调查概述

> 对应第17届专科提纲第1章：市场调查基本知识、基本程序、应用范围。
> 本章题量 9，概念为主，难度较低。

## 一句话定位

市场调查是为解决市场问题，有计划地收集、整理、分析市场信息，并给出结论和建议的活动。

## 核心概念

### 1. 市场调查的定义与原则

- 定义：以特定目的为指引，有计划地收集、整理、分析市场信息，提出解决问题方案及建议的一整套方法、技术和规程。
- 最重要的原则：**客观性/真实性**（`Q17-ZK-002` 答案 C，按题库口径）。
- 其他原则：系统性、科学性、针对性、时效性、经济性、保密性。

### 2. 市场调查的基本程序

1. 明确调查目的和调查问题。
2. 设计调查方案。
3. 收集数据。
4. 整理与分析数据。
5. 撰写调查报告。
6. 跟踪反馈。

> `Q17-ZK-004`、`Q17-ZK-006` 问“对调查过程描述最不适当”的选项，核心是排除“跳过某一步”“先收集再定目的”“调查目的可有可无”等错误说法。

### 3. 调查类型

| 分类 | 类型 | 说明 |
|---|---|---|
| 研究性质 | 探索性调查 | 了解问题特征、相关变量，定性为主（`Q17-ZK-078`） |
|  | 描述性调查 | 描述市场特征、规模、结构 |
|  | 因果性调查 | 检验因果关系 |
|  | 预测性调查 | 预测未来趋势 |
| 调查范围 | 全面调查 | 普查 |
|  | 非全面调查 | 重点、典型、抽样 |
| 时间 | 一次性调查 | 专门组织 |
|  | 经常性调查 | 连续登记 |

### 4. 应用范围

- 市场需求与潜力研究。
- 消费者行为、态度、满意度研究。
- 产品开发、测试、诊断、改造（`Q17-ZK-001`）。
- 价格、渠道、促销、广告研究。
- 竞争分析：本企业条件与竞争对手对比，制定竞争策略（`Q17-ZK-005`）。
- 宏观环境与行业趋势研究。

### 5. 市场调查的作用

- 为企业决策提供信息依据。
- 发现市场机会与风险。
- 了解消费者需求和竞争态势。
- 评估营销活动效果。
- 降低决策的不确定性。

> 市场调查不是万能的：受时间、成本、数据可得性、被调查者配合度限制；不能保证决策一定正确。

## 常考结论

1. 市场调查的起点是明确调查目的/调查问题。
2. 探索性调查用于掌握问题特征和相关变量。
3. 每一次市场调查通常只有一个核心研究目的，不是“多个明确目的”（`Q17-ZK-077` 答案：错）。
4. 问卷设计前咨询企业负责人和专业人员是必要的，但不能说“即可获取全部信息”（`Q17-ZK-081` 答案：错）。
5. 市场调查最重要的原则是客观性/真实性（题库口径）。

## 易混点

| A | B | 区别 |
|---|---|---|
| 探索性调查 | 描述性调查 | 了解问题特征 vs 描述市场状况 |
| 普查 | 抽样调查 | 全部单位 vs 部分单位 |
| 重点调查 | 典型调查 | 量上占大头 vs 质上有代表性 |
| 调查目的 | 调查目标 | 为什么调查 vs 要达到什么具体结果 |

## 答题套路

- 看到“新产品开发、测试、诊断、改造”→ 产品研究。
- 看到“与竞争对手对比、制定竞争策略”→ 竞争分析。
- 看到“了解问题特征、相关变量”→ 探索性调查。
- 看到“市场调查最重要原则”→ 客观性/真实性。
- 看到“调查过程描述不适当”→ 排除跳过步骤、目的不清、先做后定目的等选项。

## 待核对

- “市场调查最重要的原则”在不同教材中可能表述为客观性、真实性、科学性，题库答案按客观性/真实性口径。
