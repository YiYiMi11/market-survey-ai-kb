# Z07 抽样调查与估计

> 对应第17届专科提纲第7章：抽样调查设计；抽样估计。
> 本章题量 20，重点是“抽样方法识别、抽样误差、区间估计、样本量”。

## 一句话定位

抽样调查用部分单位推断总体。核心是：**怎么抽、怎么估、误差多大、样本多少**。

## 核心概念

### 1. 抽样基础

| 概念 | 含义 |
|---|---|
| 全及总体 | 所要研究的对象全体（`Q17-ZK-054`） |
| 样本 | 从总体中抽取的部分单位 |
| 全及指标 | 总体参数，确定值 |
| 抽样指标 | 样本统计量，随样本变化 |
| 抽样误差 | 随机抽样产生的代表性误差 |
| 抽样平均误差 | 抽样指标的标准差，即标准误 |
| 抽样极限误差 | 允许的最大误差范围 |

> `Q17-ZK-053`：抽样标准误差是 **样本均值的标准差**。
>
> `Q17-ZK-095`：全及指标是确定值，抽样指标围绕它变动，二者存在误差范围。
>
> `Q17-ZK-080`：只要是抽样调查，抽样误差一直存在 → 对。
>
> `Q17-ZK-092`：估计量和估计值没有区别 → 错；估计量是随机变量，估计值是具体数值。

### 2. 抽样方法

| 方法 | 做法 | 特点 |
|---|---|---|
| 简单随机抽样 | 等概率抽取 | 又称纯随机抽样；随机数表又称乱数表（`Q17-ZK-062`） |
| 系统抽样 | 排序后按固定间隔抽取 | 又称等距抽样（`Q17-ZK-057`） |
| 分层抽样 | 按层随机抽取 | 又称类型抽样（`Q17-ZK-098`） |
| 整群抽样 | 抽群，调查群内全部 | 实施方便，精度可能较低 |
| 多阶段抽样 | 分阶段抽单元 | 适合大规模调查 |
| 重点调查 | 选量上占大头的单位 | 主观选择（`Q17-ZK-003`、`Q17-ZK-007`） |
| 典型调查 | 选有代表性的单位 | 主观选择 |
| 配额抽样 | 按特征分配名额 | 非概率 |
| 便利抽样 | 就近方便 | 非概率 |
| 判断抽样 | 主观选择 | 非概率 |
| 滚雪球抽样 | 推荐链 | 稀有群体 |

> `Q17-ZK-009`：估计愿意乘坐地铁的人数比例，最可能采用 **概率抽样**。
>
> `Q17-ZK-060`：一般来说，随机抽样比非随机抽样的样本数目 **少一些**（题库口径；随机抽样效率更高）。
>
> `Q17-ZK-063`：设计效应：简单随机=1，整群>1，多阶段>1，分层<1；题干说分层>1 → 错。

### 3. 抽样误差与非抽样误差

- 抽样误差：随机抽样产生的代表性误差，可以计算和控制。
- 非抽样误差：抽样框误差、无回答误差、计量误差、记录误差等。
- `Q17-ZK-059`：非概率抽样不能用抽样误差衡量精确性 → 题干说“可以”是错误的。

### 4. 抽样估计

- 点估计：用样本统计量直接估计总体参数。
- 区间估计：给出置信区间。
- 总体参数估计方法包括点估计与区间估计（`Q17-ZK-064`）。
- 样本比例：p=m/n。100 件中 98 件优质 → p=0.98（`Q17-ZK-055`）。
- 总体比例估计：具有某特征的单元总数/总体单元总数（`Q17-ZK-096`）。
- 比例估计的统计量：大样本下用 **Z 统计量**（`Q17-ZK-056`）。

区间估计示例：

- p=80%，抽样平均误差=2%，t=2 → 区间 80%±2×2% = 76%—84%（`Q17-ZK-065`）。
- 置信度越高，区间越宽；样本量越大，区间越窄。

### 5. 样本量

影响因素：

1. 总体变异程度。
2. 允许误差/精度。
3. 置信度。
4. 抽样方法/设计效应。
5. 回答率。
6. 预算、时间。

> 样本量不随总体规模同比例增加；总体大不代表样本要同样大。

### 6. 设计效应

deff = 设计方差 / 简单随机抽样方差。

| deff | 含义 |
|---|---|
| =1 | 与简单随机抽样相同 |
| <1 | 效率更高（分层抽样） |
| >1 | 效率更低（整群、多阶段） |

### 7. 抽样框

- 抽样框：抽样单元的名录/名单/地图。
- 抽样框误差：遗漏、重复、错位、陈旧。
- 抽样框误差会导致估计偏差。

## 常考结论

1. 全及指标是确定值，抽样指标随样本变化。
2. 抽样标准误差是样本均值的标准差。
3. 估计量是随机变量，估计值是具体数值。
4. 系统抽样=等距抽样；分层抽样=类型抽样；随机数表=乱数表。
5. 重点调查和典型调查都有主观选择特征。
6. 非概率抽样不能计算抽样误差。
7. 比例估计大样本用 Z 统计量。
8. 置信区间：p±t×抽样平均误差。
9. 设计效应：分层<1，整群/多阶段>1，简单随机=1。
10. 样本量取决于变异、精度、置信度，不取决于总体规模。

## 易混点

| A | B | 区别 |
|---|---|---|
| 全及总体 | 样本 | 全体 vs 部分 |
| 全及指标 | 抽样指标 | 确定值 vs 随机变量 |
| 估计量 | 估计值 | 随机变量 vs 具体数值 |
| 抽样误差 | 非抽样误差 | 随机抽样 vs 其他误差 |
| 系统抽样 | 分层抽样 | 等距抽取 vs 按层抽取 |
| 重点调查 | 典型调查 | 量上占大头 vs 质上有代表性 |
| 抽样平均误差 | 抽样极限误差 | 标准误 vs 允许误差范围 |

## 答题套路

- 看到“按固定间隔/顺序抽取”→ 系统抽样。
- 看到“按层/类型抽取”→ 分层抽样。
- 看到“抽群调查全部”→ 整群抽样。
- 看到“占销售额 80% 的五个单位”→ 重点调查。
- 看到“随机数表”→ 乱数表。
- 看到“样本均值的标准差”→ 抽样标准误差。
- 看到“估计量 vs 估计值”→ 随机变量 vs 具体数值。
- 看到“非概率抽样计算抽样误差”→ 错。
- 看到“95.45%, t=2”→ 区间 p±2×抽样平均误差。

## 待核对

- `Q17-ZK-060`：题库认为随机抽样比非随机抽样的样本数目“少一些”，这依赖“同样精度下概率抽样效率更高”的语境；不同教材表述可能不同。
- 抽样极限误差与抽样平均误差的关系通常为 Δ=t×μ，考试看清 t 值和概率保证程度。
