# Z03 问卷及量表设计

> 对应第17届专科提纲第3章：问卷及量表的设计与应用。
> 本章题量 14，重点在“问题类型、问题顺序、量表类型、信度效度”。

## 一句话定位

问卷是结构化采集工具；量表是测量态度/特征的工具。设计问卷要解决“问什么、怎么问、怎么答、怎么排、信不信得过”。

## 核心概念

### 1. 问卷的结构

| 部分 | 内容 |
|---|---|
| 标题 | 调查主题 |
| 说明词 | 目的、保密、填答说明、致谢 |
| 甄别部分 | 筛选符合条件的被调查者（`Q17-ZK-018`） |
| 主体 | 问题、答案、回答方式 |
| 背景信息 | 性别、年龄、职业、收入等 |
| 结束语 | 致谢 |
| 编码 | 题号、选项代码 |

### 2. 问题的类型

| 类型 | 说明 | 例子 |
|---|---|---|
| 开放式 | 不提供答案，自由回答（`Q17-ZK-022`） | “请谈谈您的建议” |
| 封闭式 | 提供固定选项（`Q17-ZK-015`） | “您是否使用过？” |
| 事实性 | 问客观事实 | 年龄、品牌使用 |
| 动机性 | 问原因 | 为什么购买 |
| 态度性 | 问评价 | 满意度 |
| 假设性 | 问假设情境 | 如果涨价会怎样 |

### 3. 问题顺序

原则：

- 先易后难。
- 先封闭后开放。
- 敏感问题、背景信息放后面。
- 能引起兴趣的问题放前面（`Q17-ZK-019` 说“放后面”是错误的）。
- 按逻辑顺序排列，避免顺序效应。

### 4. 问题措辞

- 通俗易懂，避免专业行话。
- 避免诱导、倾向性、双重问题、否定式。
- 避免涉及隐私的直白问法。
- 提问时按问卷顺序、使用问卷措辞、语速适中；不能随意增减问题（`Q17-ZK-036`）。
- 措辞不当会影响回答率和回答质量（`Q17-ZK-082`）。

### 5. 量表类型

| 量表 | 做法 | 数据类型 |
|---|---|---|
| 固定总数量表 | 把 100 分/10 分分配给多个特性（`Q17-ZK-016`） | 定比/定距 |
| 排序量表 | 对对象排序，赋 1、2、3… | 定序 |
| 配对比较量表 | 两两比较 | 定序 |
| 李克特量表 | 同意程度 5/7 级 | 定序/近似定距 |
| 语义差别量表 | 反义形容词数轴 | 定距 |
| 等级量表 | 直接评分/分级 | 定序/定距 |

> `Q17-ZK-017`：品尝五种冰淇淋，按 1—5 排列喜好程度 → **顺序尺度**。

### 6. 信度与效度

| 概念 | 含义 | 类型 |
|---|---|---|
| 信度 | 测量结果的稳定性/一致性 | 再测信度、复本信度、分半信度、内部一致性 |
| 效度 | 是否测到要测的东西 | 内容效度、效标效度、结构效度 |

- 复本信度：两个平行量表测量同一概念，求两次结果的相关系数（`Q17-ZK-021`）。
- 再测信度：同一量表前后两次测量。
- 分半信度：题目分两半，求两半得分相关。
- 内部一致性：Cronbach's α。
- 信度系数 0.8—0.9：题库认为“非常可信，完全接受，不需调整”（`Q17-ZK-014` 答案 C）。一般教材中 0.8 以上已较好，但是否“完全接受、不需调整”要看具体教材。
- 问卷设计保证数据在一定条件下稳定 → **可靠性原则**（`Q17-ZK-020`）。

### 7. 编码

- 预编码：封闭式问题，设计时分配代码。
- 后编码：开放式问题，回收后归类编码。
- 分组编码法：用数字/文字/符号表示编码对象属性（`Q17-ZK-089` 题干定义不准确，答案：错）。
- 编码要求：唯一、完整、可核查。

### 8. 问卷设计原则

- 目的性：围绕调查目标。
- 逻辑性：问题顺序合理。
- 通俗性：语言易懂。
- 中立性：不诱导。
- 简洁性：长度适当。
- 可靠性：结果稳定。
- 可维护性/可操作性：便于编码、录入、分析。

## 常考结论

1. 开放式问题用于定性探索（`Q17-ZK-083`）。
2. 甄别问题用于筛选合格被调查者。
3. 问题顺序：先易后难、先封闭后开放、敏感后置、兴趣题前置。
4. 固定总数量表是把固定分数分配给多个特性。
5. 排序/配对比较得到定序数据。
6. 两个平行量表 → 复本信度。
7. 信度系数 0.8—0.9 → 题库认为非常可信。
8. 措辞不当会影响回答率和回答质量。

## 易混点

| A | B | 区别 |
|---|---|---|
| 开放式 | 封闭式 | 自由回答 vs 固定选项 |
| 排序量表 | 配对比较量表 | 直接排序 vs 两两比较 |
| 固定总数量表 | 李克特量表 | 分配固定总分 vs 同意程度评分 |
| 再测信度 | 复本信度 | 同一量表前后两次 vs 两个平行量表 |
| 信度 | 效度 | 稳定性 vs 准确性 |
| 预编码 | 后编码 | 封闭式 vs 开放式 |

## 答题套路

- 看到“请您谈谈……”→ 开放式。
- 看到“固定选项”→ 封闭式。
- 看到“筛选合格被调查者”→ 甄别部分。
- 看到“按 1—5 排列喜好”→ 顺序尺度/排序量表。
- 看到“固定总分分配给多个特性”→ 固定总数量表。
- 看到“两个平行量表”→ 复本信度。
- 看到“前后两次测量”→ 再测信度。
- 看到“数据稳定”→ 可靠性原则。
- 看到“兴趣题放后面”→ 错，应放前面。

## 待核对
