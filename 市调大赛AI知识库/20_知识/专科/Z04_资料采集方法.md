# Z04 资料采集方法

> 对应第17届专科提纲第4章：定性数据收集、定量数据收集、一手和二手数据收集。
> 本章题量 16，重点是“方法—适用场景”的对应。

## 一句话定位

资料采集方法分两条线：**一手 vs 二手**，**定性 vs 定量**。考试常问“这个调查项目最适合什么方法”。

## 核心概念

### 1. 一手资料与二手资料

| 维度 | 一手资料 | 二手资料 |
|---|---|---|
| 来源 | 调查者直接采集 | 已有资料 |
| 方法 | 访问、观察、实验、问卷 | 文案调查、数据库、年鉴、网络 |
| 优点 | 针对性强、口径可控 | 成本低、速度快、历史长 |
| 缺点 | 成本高、周期长 | 口径可能不一致、时效差 |

> `Q17-ZK-030`：消费者本人填答的消费习惯数据属于 **一手资料**，不是二手资料。
>
> `Q17-ZK-032`：文案调查法收集的资料叫 **二手资料**。
>
> `Q17-ZK-028`：文案调查的优点包括 **不受时空限制**、成本低、速度快。

### 2. 定性调查方法

| 方法 | 做法 | 适用 |
|---|---|---|
| 深层访谈 | 一对一、非结构化、深入追问 | 敏感问题、复杂行为、员工跳槽原因（`Q17-ZK-027`） |
| 小组座谈 | 6—10 人群体互动 | 探索新概念、广告创意 |
| 投影技法 | 联想、完成、构造、表达 | 挖掘潜在动机 |
| 德尔菲法 | 专家匿名、多轮反馈 | 长期预测、指标筛选、选址因素（`Q17-ZK-025`） |
| 观察法 | 记录实际行为 | 行为模式、服务质量 |
| 文案调查 | 收集已有资料 | 背景、趋势、行业数据 |

> `Q17-ZK-084`：小组座谈法和深层访谈法都属于 **非标准式面访**。答案：对。
>
> `Q17-ZK-085`：标准化访问是结构化访问，不是“按粗略提纲自由访问”；题干说反 → 错。

### 3. 定量调查方法

| 方法 | 特点 | 适用 |
|---|---|---|
| 面访 | 灵活、可追问、成本高 | 复杂问卷、需要展示（`Q17-ZK-029`） |
| 电话调查 | 快速、短问卷 | 快速回访、行风评议 |
| 邮寄调查 | 成本低、无访问员偏差、回收率低 | 敏感问题、时效不高 |
| 网络调查 | 快速、低成本、覆盖偏差 | 年轻群体、快速调查 |
| 实验法 | 控制变量、检验因果 | 营销组合测试 |
| 观察法 | 记录行为 | 客流、货架、服务 |

### 4. 德尔菲法

- 专家匿名、多轮征询、每轮反馈、逐步收敛。
- 成败关键：**专家的选择**（`Q17-ZK-024`）。
- 优点：匿名性、反馈性、量化性。
- 不包括的优点：**客观性**（`Q17-ZK-026` 答案 C；专家判断仍带主观性）。
- 适用：长期预测、指标筛选、方案评估、选址因素。
- 不适用：需要直接了解消费者行为/态度的一手调查。

### 5. 文案调查法

- 定义：通过收集、整理、分析已有文献和二手资料获取信息。
- 优点：成本低、速度快、不受时空限制、可做历史趋势。
- 缺点：资料可能过时、口径不一致、针对性不足、质量难判断。
- 适用：市场供求趋势、市场覆盖率、行业背景、相关回归分析的历史数据。
- 不适用：顾客满意度、购买动机等需要一手数据的研究。

### 6. 观察法

- 类型：参与/非参与、公开/隐蔽、结构/非结构、自然/实验。
- 优点：记录实际行为，不依赖自我报告。
- 缺点：难以观察态度/动机；观察者主观偏差（`Q17-ZK-087`）。
- 遥感调查：通过卫星/航空影像获取农作物种植种类和面积，属于 **观察法**（`Q17-ZK-031`）。

### 7. 访问实施与记录

- 访问员应按问卷顺序、使用问卷措辞、语速适中，不能随意增减问题（`Q17-ZK-036`）。
- 开放式问题记录：使用被调查者自己的语言、记录全部相关内容、边记录边重复确认；不能“过后补记”（`Q17-ZK-040`）。
- 记录粗心造成的误差 → **调查员误差**（`Q17-ZK-042`）。
- 敏感问题在个别访谈中可能难以回答（`Q17-ZK-086` 答案：错？按题库答案 B，说明题干“难以回答”不被认为正确，注意具体表述）。

### 8. 调查单位与报告单位

> `Q17-ZK-010`：工业企业普查中，每个工业企业 **既是调查单位又是报告单位**。

## 常考结论

1. 文案调查收集的是二手资料；消费者自己填答的是一手资料。
2. 深层访谈适合敏感/复杂/个体行为原因；小组座谈适合群体互动/探索。
3. 德尔菲法成败关键是专家选择；优点不包括客观性。
4. 遥感调查属于观察法。
5. 开放式问题不能过后补记。
6. 记录粗心 → 调查员误差。
7. 标准化访问是结构化访问。
8. 一手资料针对性强但成本高；二手资料成本低但口径可能不一致。

## 易混点

| A | B | 区别 |
|---|---|---|
| 一手资料 | 二手资料 | 直接采集 vs 已有资料 |
| 深层访谈 | 小组座谈 | 一对一 vs 群体互动 |
| 德尔菲法 | 头脑风暴 | 匿名多轮 vs 面对面自由联想 |
| 文案调查 | 二手资料 | 方法 vs 资料 |
| 观察法 | 访问法 | 记录行为 vs 询问自我报告 |
| 调查单位 | 报告单位 | 接受调查的个体 vs 负责填报的单位 |

## 答题套路

- 看到“员工跳槽原因、敏感/复杂行为”→ 深层访谈。
- 看到“专家匿名、多轮反馈、长期预测”→ 德尔菲。
- 看到“已有资料、年鉴、数据库”→ 文案调查/二手资料。
- 看到“遥感、农作物面积”→ 观察法。
- 看到“消费者本人填答”→ 一手资料。
- 看到“开放式问题记录”→ 不能过后补记。
- 看到“记录粗心”→ 调查员误差。
- 看到“标准化访问”→ 结构化访问。
