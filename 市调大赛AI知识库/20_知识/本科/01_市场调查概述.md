# 01 市场调查概述

> 对应第17届本科提纲第1章：市场调查基本知识、基本程序、应用范围。
> 本章题量 43，以概念辨析和“属于/不属于”型选择题为主。

## 一句话定位

市场调查不是“发问卷”，而是围绕特定决策问题，有计划地收集、整理、分析市场信息，并给出方案与建议的一整套科学方法、技术和规程。

## 核心概念

### 1. 市场调查的定义

教材口径：以特定研究目的为指引，有计划地收集、整理、分析市场的信息资料，提出解决问题的方案及建议的一整套科学方法、技术及规程。

拆成四个关键词：

| 关键词 | 含义 | 常见干扰 |
|---|---|---|
| 特定目的 | 服务于营销决策问题 | 为调查而调查、先定结论再找数据 |
| 有计划 | 有方案、有程序、有质量控制 | 随意访谈、只发朋友圈问卷 |
| 系统性 | 收集—整理—分析—报告完整链条 | 只收集不分析 |
| 方法技术 | 抽样、问卷、量表、统计模型 | 把市场调查等同于访问技巧 |

### 2. 市场调查的作用与边界

作用：

- 降低决策不确定性，提供市场信息依据。
- 发现市场机会与威胁，评估营销组合效果。
- 了解消费者需求、态度、行为和满意度。
- 监测竞争格局与市场环境变化。

边界：

- 调查不能保证决策一定正确，只能降低信息不对称。
- 受时间、预算、数据可得性和被调查者配合程度限制。
- 涉及商业机密、隐私、伦理时，调查可能不可行。
- 并非所有情形都宜开展调查：决策时间极紧、信息已充足、调查成本高于收益、问题无法通过调查回答时，不宜调查。

### 3. 市场调查的基本程序

按题库口径，可记为六步：

1. **确定调查问题**：明确调查目的、调查对象和调查范围，界定调查问题。
2. **设计调查方案**：确定调查内容、方式方法、时间、进度、预算、组织与质量控制。
3. **收集数据**：二手资料检索、访问、观察、实验等。
4. **处理与分析数据**：审核、编码、录入、分组、统计分析与解释。
5. **撰写调查报告**：书面报告与口头演示。
6. **跟踪反馈**：评估调查结果的应用效果，必要时补充调查。

> 题库口径提醒：`Q17-BK-002` 把“确定调查对象和调查范围”归入“确定调查问题”环节，而不是“拟定调查方案”。这与社会调查教材的常见表述略有差异，考试按题库口径记。

### 4. 调查类型

| 分类依据 | 类型 | 关键特征 |
|---|---|---|
| 研究性质 | 探索性调查 | 问题不明确，定性为主，小样本，灵活 |
|  | 描述性调查 | 回答 who/what/when/where/how，横截面或纵向 |
|  | 因果性调查 | 检验“为什么”，常用实验法 |
|  | 预测性调查 | 预测未来趋势，常用专家咨询、趋势分析、时间序列 |
| 调查对象 | 消费者调查 / 产业市场调查 | 个人消费者 vs 组织购买者 |
| 流通环节 | 批发市场调查 / 零售市场调查 | 按市场环节划分 |
| 调查范围 | 全面调查 / 非全面调查 | 普查 vs 重点、典型、抽样调查 |
| 时间属性 | 经常性调查 / 一次性调查 | 连续登记 vs 专门组织 |
| 数据来源 | 一手数据调查 / 二手数据调查 | 直接采集 vs 已有资料 |
| 采集方式 | 文案、访问、观察、实验 | 询问/观察/实验/文献 |

> 预测性调查的常用方法：专家咨询、趋势分析、时间序列预测（`Q12-BK-060` 答案 BDE）。市场实验法更偏因果性调查。

### 5. 市场调查的应用范围

- 市场需求与市场潜力研究：现有规模、潜在规模、市场占有率。
- 消费者研究：购买动机、使用习惯、态度、满意度、品牌偏好。
- 产品研究：新产品概念、包装、品牌名称、产品测试。
- 价格研究：定价、价格弹性、价格敏感度。
- 渠道研究：渠道结构、覆盖、终端表现。
- 促销与广告研究：广告主题、媒体、投放监测、接受效果。
- 竞争研究：竞争对手、竞争格局、竞争策略。
- 环境研究：宏观环境、行业趋势。

> `Q17-BK-060`：广告研究包括广告主题、广告媒体、广告投放监测、广告接受效果；**消费者形态研究不属于广告研究**。
>
> `Q13-BK-009 / Q17-BK-009`：同时要“渗透水平与深度、使用者/购买者人口统计特征、使用习惯和购买习惯”，对应 **U&A（消费者使用与态度研究）**，不是产品概念测试或包装测试。

### 6. 市场调查行业与组织

- 调查提供者：企业调查部门、独立调查公司、学术性调查机构、政府统计部门。
- 调查使用者：企业营销/战略部门、政府、媒体、研究机构。
- 组织模式：题库中企业调查部门、独立调查公司、学术性调查机构的组织模式多采用 **矩阵式**（`Q12-BK-006`）。
- 调查行业伦理：保密、知情同意、客观、不误导、不侵犯隐私。

### 7. 企业可控与不可控因素

| 类别 | 内容 | 是否可控 |
|---|---|---|
| 营销组合 | 产品、价格、渠道、促销 | 可控 |
| 企业内部资源 | 资金、人员、技术、品牌 | 基本可控 |
| 外部环境 | 竞争对手、消费者、供应商、政策法律、经济、技术、社会文化 | 不可控 |

> `Q12-BK-011` 问“企业不可控制”的内容，答案是 **竞争对手**；产品、价格、渠道都属可控营销组合。

## 常考结论

1. 市场调查是“方法、技术及规程”的整套体系，不是单一调查方法。
2. 市场调查的起点是确定调查问题，不是设计问卷。
3. 探索性调查解决“问题是什么”，描述性调查解决“是什么样”，因果性调查解决“为什么”，预测性调查解决“将来会怎样”。
4. 普查是一次性、全面、专门组织的调查；统计报表是经常性、自上而下的上报制度。
5. 重点调查的单位数少、能反映总体基本趋势，但不能推断总体总量；典型调查用于深入解剖典型，也不能直接推断总体。
6. 多个调查项目合并实施通常不可行（`Q13-BK-075` 答案：错），因为目标、对象、时间、预算不同，合并会牺牲针对性。

## 易混点

| A | B | 区别 |
|---|---|---|
| 市场调查 | 市场研究 | 调查偏数据采集；研究还包括分析、模型、决策建议，范围更宽 |
| 探索性调查 | 描述性调查 | 探索性偏定性、小样本、问题不明确；描述性偏结构化、大样本、描述特征 |
| 因果性调查 | 预测性调查 | 因果性检验变量间因果关系；预测性外推未来 |
| 普查 | 抽样调查 | 普查调查全部单位；抽样调查抽部分单位并推断总体 |
| 重点调查 | 典型调查 | 重点调查选“量上占大头”的单位；典型调查选“质上有代表性”的单位 |
| 调查对象 | 调查单位 | 调查对象是总体范围；调查单位是具体被调查的个体 |
| 调查时间 | 调查期限 | 调查时间是资料所属时间；调查期限是工作起止时间 |

## 答题套路

- 看到“属于市场调查应用范围”的选项，优先排除：与市场无关的纯学术研究、纯生产技术研究、已经完成且无需决策的历史研究。
- 看到“不宜开展调查”，优先选：决策时间极紧、信息已足够、成本大于收益、问题无法通过调查回答。
- 看到“调查程序”，按“确定问题—设计方案—收集—处理—报告”排序。
- 看到“预测性调查方法”，选专家咨询、趋势分析、时间序列；不要选市场实验法。
- 看到“广告研究”，排除消费者形态研究、产品性能测试等非广告环节。

## 待核对

- “确定调查对象和范围”归属“确定调查问题”还是“拟定调查方案”，题库按前者（`Q17-BK-002`），部分教材可能按后者。考试以题库/本校教材为准。
- 调查行业组织模式“矩阵式”是题库口径（`Q12-BK-006`），不同教材可能有差异。
