# 05 数据处理与报告

> 对应第17届本科提纲第5章：调查数据的处理和汇总；调查报告的撰写和演示。
> 本章题量 38，重点在“流程顺序”“方法名称”“图表选择”“报告结构”。

## 一句话定位

数据处理把“回收来的原始问卷”变成“可分析、可解释的数据”；报告把“分析结果”变成“决策者可用的结论和建议”。

## 核心概念

### 1. 数据处理流程

1. **问卷接收与检查**：检查完整性、有效性、时效性。
2. **数据审核**：完整性、准确性、一致性、及时性。
3. **数据净化**：处理缺失值、异常值、逻辑矛盾、重复记录。
4. **编码**：给问题和选项分配代码。
5. **录入**：录入、校验、纠错。
6. **插补**：处理缺失值。
7. **分组与汇总**：统计分组、频数分布、交叉表。
8. **制图/制表**：可视化与统计表。
9. **分析**：描述统计、推断统计、模型分析。

> `Q13-BK-027 / Q17-BK-028`：对数据分类或分组前所做的必要处理，称为 **预处理**。

### 2. 数据审核

| 审核维度 | 内容 |
|---|---|
| 完整性 | 问卷是否缺页、缺题、缺项 |
| 准确性 | 回答是否真实、合理、无错误 |
| 一致性 | 前后回答是否矛盾、逻辑是否自洽 |
| 及时性 | 是否在规定时间内回收 |
| 规范性 | 字迹、编码、填写方式是否规范 |

审核方法：逻辑检查、计算检查、经验判断、回访核实。

> `Q12-BK-025`：检查各组结构比例之和是否等于 1 或 100%，属于 **逻辑审核/一致性检查**。

### 3. 数据净化

- 缺失值处理：删除、插补、保留。
- 异常值处理：识别、核实、修正、删除、保留并稳健分析。
- 逻辑矛盾：跳答错误、多选与单选冲突、年龄与职业矛盾。
- 重复记录：去重。
- 无效问卷：不完整、明显乱填、关键信息缺失、非目标对象。

> `Q15-BK-079`：采用统计软件进行逻辑分析是常用的数据净化方法。答案：对。

### 4. 缺失值插补

| 方法 | 做法 | 适用 | 注意 |
|---|---|---|---|
| 均值/中位数/众数插补 | 用样本统计量替代 | 连续/分类变量 | 会低估方差 |
| 热卡插补 | 在同一数据集/同一次调查中找相似单元 | 调查数据 | `Q13-BK-028`、`Q16-BK-030` |
| 冷卡插补 | 用历史数据/外部数据插补 | 有历史资料 | 口径可能不一致 |
| 回归插补 | 用其他变量预测缺失值 | 变量相关较强 | 依赖模型 |
| 多重插补 | 生成多个插补数据集，合并结果 | 复杂缺失机制 | 计算量大、解释复杂 |
| 推理插补 | 根据逻辑关系推算 | 有确定关系 | 插补值不一定是真值（`Q17-BK-079`） |

> `Q16-BK-029`：分类变量常用 **众数插补**。
>
> `Q16-BK-026`：存在插补数据时，估计量的抽样方差通常会 **增大**（因为插补引入不确定性）。

### 5. 编码

- 预编码：封闭式问题在设计时就编码。
- 后编码：开放式问题回收后归类编码。
- 编码表：变量名、题号、选项代码、缺失值代码。
- 编码原则：唯一、可逆、覆盖全部选项、缺失值单独编码。

### 6. 统计分组

| 概念 | 含义 |
|---|---|
| 单变量分组 | 按一个标志分组 |
| 多变量分组 | 按两个及以上标志分组 |
| 组距 | 每组上下限之差 |
| 组数 | 分组的数量 |
| 组中值 | (下限+上限)/2 |
| 频数 | 落入每组的单位数 |
| 频率 | 频数/总数 |

分组原则：

- 穷尽：所有单位都能归入某一组。
- 互斥：每个单位只归入一组。
- 组距尽量相等；分布极度倾斜时可不等距分组（`Q15-BK-026`）。
- 上限不计入：`[a, b)` 原则（`Q12-BK-080`）。
- 组数适中：一般 5—15 组，取决于样本量和数据分布。

### 7. 统计图选择

| 图形 | 适用 | 关键特征 |
|---|---|---|
| 条形图 | 分类数据 | 条形分开、宽度固定 |
| 饼图 | 分类数据的构成 | 各部分占比之和 100% |
| 直方图 | 连续分组数据 | 矩形连续、面积表示频数 |
| 茎叶图 | 小样本连续数据 | 保留原始数值、显示分布形状 |
| 箱线图 | 分布特征、异常值 | 中位数、四分位数、须、离群点 |
| 散点图 | 两变量关系 | 相关方向与强度 |
| 折线图 | 时间序列 | 趋势、波动、周期 |
| 雷达图 | 多指标比较 | 多维轮廓 |

> `Q15-BK-030`：直方图用于连续分组数据，矩形连续排列；条形图用于分类数据，条形分开排列。
>
> `Q12-BK-027`：地区、季度、商品、销售额四个字段，要反映各种商品在各地区和各季度的销售情况，宜绘制 **多变量条形图/分组条形图**（题库答案 A）。
>
> `Q16-BK-027`：既反映分布状况又保持原始数据的图形是 **茎叶图**。
>
> `Q14-BK-029`：常用来反映现象分布特征的统计图是 **直方图**。

### 8. 统计表

| 部分 | 内容 |
|---|---|
| 标题 | 表的内容、时间、地点 |
| 表头 | 列标题、分组标志 |
| 表体 | 数据 |
| 注释 | 口径、单位、说明 |
| 来源 | 数据来源 |

设计要求：标题简明、栏目清晰、数据对齐、单位统一、注释完整、避免过多线条（`Q14-BK-067`）。

### 9. 调查报告的结构

| 部分 | 内容 |
|---|---|
| 标题 | 调查主题、范围、时间 |
| 目录 | 章节与页码 |
| 摘要 | 目的、方法、主要发现、结论建议 |
| 正文 | 调查背景、调查方法、调查结果、结论与建议 |
| 附录 | 问卷、抽样方案、统计表、原始数据、编码表 |
| 参考文献 | 引用资料 |

> `Q13-BK-029 / Q15-BK-029`：不包含在正文部分的是 **附录/参考文献**。
>
> `Q13-BK-030`：调查报告附录中应包含 **问卷、抽样方案、统计表、原始数据** 等。
>
> `Q12-BK-079`：演示报告是书面报告的浓缩版本，应包含主要观点和重要结论。答案：对。

### 10. 报告撰写原则

- 客观：以数据为依据，不主观臆断。
- 准确：概念、数据、引用准确。
- 简明：重点突出、语言精炼。
- 可读：结构清晰、图表得当、术语解释。
- 针对性：围绕调查目的和决策问题。
- 观点与数据统一（`Q15-BK-028`）。
- 统计推断遵循谨慎原则（`Q16-BK-079`）。
- 公正性：不偏袒委托方，如实报告（`Q17-BK-027`）。
- 科学性/真实性：过程可追溯、方法可复核（`Q16-BK-067`）。
- 运用大量数据反映发展变化时，常用 **对比法/图表法**（`Q14-BK-030`）。

### 11. 报告演示

- 结构：开场—目的—方法—发现—结论—建议—问答。
- 视觉：一页一个观点、图表简洁、重点突出。
- 口头：控制时间、面向听众、避免照读。
- 材料：PPT、讲义、附录。

## 常考结论

1. 数据分类/分组前的必要处理叫预处理。
2. 热卡插补用同一数据集/同一次调查；冷卡用历史/外部数据。
3. 开放式问题用后编码；封闭式用预编码。
4. 直方图用于连续数据，条形图用于分类数据。
5. 茎叶图既反映分布又保留原始数据。
6. 报告正文包括背景、方法、结果、结论建议；附录/参考文献不在正文。
7. 截止日期后回收的问卷应废弃。
8. 上限不计入：边界值归入上一组。
9. 插补会增大估计量的抽样方差。
10. 统计表要求标题、表头、表体、注释、来源完整。

## 易混点

| A | B | 区别 |
|---|---|---|
| 审核 | 净化 | 审核是检查问题；净化是处理问题 |
| 预处理 | 统计分析 | 分组前的整理 vs 分组后的分析 |
| 热卡插补 | 冷卡插补 | 同一数据集 vs 历史/外部数据 |
| 预编码 | 后编码 | 封闭式 vs 开放式 |
| 直方图 | 条形图 | 连续数据、矩形相连 vs 分类数据、条形分开 |
| 茎叶图 | 箱线图 | 保留原始值 vs 展示四分位数与异常值 |
| 正文 | 附录 | 核心发现与结论 vs 问卷、原始数据、技术细节 |
| 书面报告 | 演示报告 | 完整详细 vs 浓缩提炼 |

## 答题套路

- 看到“分组前处理”→ 预处理。
- 看到“同一数据集/同一次调查插补”→ 热卡。
- 看到“历史数据/外部数据插补”→ 冷卡。
- 看到“开放式问题编码”→ 后编码。
- 看到“连续数据分布”→ 直方图。
- 看到“分类数据比较”→ 条形图。
- 看到“保留原始数据+看分布”→ 茎叶图。
- 看到“报告正文不包括”→ 附录、参考文献、致谢。
- 看到“截止日期后回收”→ 废弃。
- 看到“边界值归组”→ 上限不计入。

## 待核对

- 插补方法名称在不同教材中略有差异（热卡/冷卡、均值插补、回归插补、多重插补），考试以题干定义为准。
- 报告正文的具体章节顺序可能因调查类型不同而调整，但“背景—方法—结果—结论建议”是通用骨架。
