# 02 数据收集

> 对应第17届本科提纲第2章：定性与定量数据收集的方法；市场调查的组织与实施。
> 本章题量 81，是全书题量第二大的章节，重点在“方法—适用场景—优缺点—误差来源”的对应。

## 一句话定位

数据收集要解决两个问题：**用什么方法拿到数据**，以及**怎样组织调查员和现场过程，保证数据质量**。

## 核心概念

### 1. 一手数据与二手数据

| 维度 | 一手数据 | 二手数据 |
|---|---|---|
| 来源 | 调查者直接采集 | 政府、行业、企业、数据库、文献等已有资料 |
| 优点 | 目的匹配、口径可控、时效可控 | 成本低、速度快、历史跨度长、可做背景分析 |
| 缺点 | 成本高、周期长、可能打扰被调查者 | 口径不一致、时效性差、针对性不足、质量难判断 |
| 典型方法 | 访问、观察、实验、问卷 | 文案调查、年鉴、统计数据库、网络资料 |

二手数据审核重点：**可比性、准确性、时效性、完整性、口径一致性**（`Q14-BK-027`）。

### 2. 定性调查与定量调查

| 维度 | 定性调查 | 定量调查 |
|---|---|---|
| 目的 | 探索“为什么”“怎么样” | 测量“多少”“比例”“关系” |
| 样本 | 小样本、目的性抽样 | 大样本、概率抽样为主 |
| 工具 | 访谈提纲、投影技法、观察记录 | 结构化问卷、量表、实验设计 |
| 分析 | 归纳、编码、主题分析 | 描述统计、推断统计、模型 |
| 典型方法 | 焦点小组、深层访谈、投影技法、德尔菲、头脑风暴、案例研究 | 面访、电话、邮寄、网络、实验、固定样本、统计报表 |
| 局限 | 不能外推总体 | 难以解释深层动机 |

> `Q13-BK-004`：座谈会（焦点小组）属于定性调查，不属于定量调查。

### 3. 文案调查法

- 定义：通过收集、整理、分析已有文献和二手资料获取信息。
- 适用：市场供求趋势、市场覆盖率、行业背景、相关与回归分析的历史数据。
- 不适用：需要直接了解消费者态度、满意度、购买动机等一手数据的情形（`Q14-BK-010`）。
- 优点：低成本、快速、可追溯、适合长期趋势。
- 缺点：资料可能过时、口径不一致、原始目的不匹配、无法控制质量。

### 4. 观察法

| 分类 | 类型 | 说明 |
|---|---|---|
| 是否介入 | 参与观察 / 非参与观察 | 观察者是否进入被观察情境 |
| 是否公开 | 公开观察 / 隐蔽观察 | 被观察者是否知道 |
| 结构化程度 | 结构观察 / 非结构观察 | 是否有明确观察项目与记录表 |
| 环境 | 自然观察 / 实验观察 | 自然环境 vs 控制环境 |

- 优点：记录实际行为，不依赖被调查者自我报告；调查员不与被调查者直接接触（`Q13-BK-016` 选直接观察法）。
- 缺点：难以观察态度、动机、隐私行为；观察者偏差；只能记录现象，难以解释原因。
- 神秘顾客：属于观察法/体验式调查，常用于服务质量监测。
- 前期观察对后期观察的影响：题库称为 **主效应**（`Q13-BK-013`、`Q15-BK-013`），属于顺序效应/测验效应。注意与实验设计中的“主效应”区分。

### 5. 访问调查法

| 方法 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 面访（入户/拦截） | 灵活性高、可追问、可展示卡片、应答率高 | 成本高、访问员偏差、入户难、隐私顾虑 | 复杂问卷、需要解释、需要展示 |
| 电话调查 | 速度快、成本较低、覆盖广、可控制访问员 | 问卷不能太长、难以展示、拒访多、样本代表性问题 | 短问卷、快速回访、行风评议 |
| 邮寄调查 | 成本低、无访问员偏差、适合敏感问题 | 回收率低、时效差、无法追问、样本偏差 | 敏感问题、时效要求不高、经费紧张 |
| 网络调查 | 成本低、速度快、可随机化、便于统计 | 覆盖偏差、重复填答、样本真实性问题 | 年轻群体、企业内部、快速调查 |
| 固定样本 | 连续追踪、可比性强 | 样本老化、代表性下降、成本高 | 连续跟踪调查、广告效果监测 |

关键结论：

- 没有调查员偏差的是 **邮寄调查**（`Q14-BK-015`），不是观察法；观察法有观察者偏差。
- 调查员不与被调查对象直接接触的是 **直接观察法**（`Q13-BK-016`）。
- 邮寄调查不适合突发性事件调查（时效差，`Q14-BK-009`）。
- 实施力控制程度最低：题库答案给 **入户面访**（`Q13-BK-015`）。这一答案与“邮寄调查过程控制最低”的常见表述有冲突，见“待核对”。

### 6. 焦点小组（小组座谈）

- 规模：通常 6—10 人，1.5—2 小时。
- 成员：同质性较高，避免相互认识、避免竞争关系。
- 主持：主持人中立、会引导、会追问，不能暗示答案。
- 优点：群体互动能激发新想法；适合探索性研究、概念测试、广告创意测试。
- 缺点：样本小不能外推；主持人偏差；从众效应；话题敏感时不适合。
- 起源：精神病医生所用的群体疗法（`Q16-BK-007`）。

### 7. 深层访谈

- 一对一、非结构化、追问深入。
- 适用：敏感话题、复杂行为、专业人士、竞争机密。
- 优点：深入、无群体压力、可灵活追问。
- 缺点：成本高、样本小、依赖访谈员技巧、难以量化。

### 8. 投影技法

| 类型 | 做法 | 例子 |
|---|---|---|
| 联想技法 | 给刺激词，让被调查者说出联想 | 词语联想 |
| 完成技法 | 补全句子/故事 | 句子完成、故事完成 |
| 构造技法 | 看图讲故事 | 主题统觉测验 |
| 表达技法 | 角色扮演、绘画、排序 | 角色扮演 |

适用：挖掘潜在动机、敏感话题、儿童/特殊群体。局限：解释主观、信度效度难保证、样本小。

### 9. 德尔菲法

- 专家匿名、多轮征询、每轮反馈统计结果、逐步收敛。
- 优点：避免权威压制、集思广益、适合长期预测。
- 缺点：周期长、专家选择主观、可能趋同、不能保证准确。
- 与头脑风暴区别：德尔菲匿名、多轮、有反馈；头脑风暴面对面、自由联想、延迟评判。

### 10. 实验法

| 概念 | 含义 |
|---|---|
| 实验组 | 接受实验处理的一组 |
| 对照组 | 不接受处理或接受安慰剂的一组 |
| 前测/后测 | 处理前后各测量一次 |
| 随机化 | 随机分配实验单位，控制混杂因素 |
| 内部效度 | 实验处理与结果之间的因果关系是否成立 |
| 外部效度 | 实验结果能否推广到其他情境/人群 |
| 交互效应 | 测试过程与实验处理相互作用，影响结果 |
| 实验单位 | 接受实验处理的个体/组织 |

- 实验法适合检验因果关系，不适合描述性调查。
- 内部效度威胁：历史、成熟、测验、工具、选择、流失、回归均值。
- 外部效度威胁：样本代表性、情境人为性、多次测试反应。
- `Q14-BK-012`：测试的交互效应会影响实验的 **外部效度**。

### 11. 其他数据收集方式

- 普查：一次性、全面、专门组织，适合人口普查、经济普查。
- 统计报表：经常性、自上而下布置、自下而上上报，适合常规统计。
- 遥感调查：通过卫星/航空影像获取农作物种植面积、土地利用等信息。
- 联网直报：企业通过统计平台直接上报数据。
- 固定样本：同一批被调查者连续追踪。

### 12. 调查组织与实施

1. 调查员招聘与培训：统一口径、熟悉问卷、掌握追问技巧、遵守伦理。
2. 预调查：检验问卷、流程、样本可行性。
3. 现场质量控制：陪访、回访、录音、GPS、逻辑校验、进度监控。
4. 调查员监督与评估：工作量、质量、作弊识别。
5. 调查员手册：供调查员使用的操作指南。
6. 伦理与隐私：知情同意、保密、不诱导、不伤害。

## 常考结论

1. 定性方法：焦点小组、深层访谈、投影技法、德尔菲、头脑风暴；定量方法：面访、电话、邮寄、网络、实验、固定样本。
2. 观察法适合行为记录，不适合态度/动机；访问法适合态度/动机，但可能有访问员偏差。
3. 邮寄调查无访问员偏差，但回收率低、时效差。
4. 焦点小组不能外推总体，适合探索性研究。
5. 德尔菲法匿名、多轮、反馈；头脑风暴面对面、自由联想、延迟评判。
6. 实验法适合因果推断；内部效度看因果是否成立，外部效度看能否推广。
7. 文案调查适合历史趋势和背景分析，不适合直接测度顾客满意度。

## 易混点

| A | B | 区别 |
|---|---|---|
| 观察法 | 访问法 | 观察行为 vs 询问自我报告 |
| 焦点小组 | 深层访谈 | 群体互动 vs 一对一深入 |
| 德尔菲法 | 头脑风暴 | 匿名多轮反馈 vs 面对面自由联想 |
| 文案调查 | 二手数据 | 文案调查是方法，二手数据是数据来源 |
| 普查 | 统计报表 | 一次性专门组织 vs 经常性上报制度 |
| 实验法 | 观察法 | 主动操纵变量 vs 被动记录行为 |
| 内部效度 | 外部效度 | 因果是否成立 vs 能否推广 |
| 邮寄调查 | 网络调查 | 都无访问员偏差，但网络调查覆盖偏差更突出、填答环境更不可控 |

## 答题套路

- 先判断题目问的是“方法分类”“适用场景”还是“误差来源”。
- 看到“敏感问题、经费紧张、时效不高”→ 邮寄调查。
- 看到“快速、短问卷、行风评议”→ 电话调查。
- 看到“复杂问卷、需要展示、需要追问”→ 面访。
- 看到“行为记录、神秘顾客”→ 观察法。
- 看到“群体互动、探索新概念”→ 焦点小组。
- 看到“专家匿名、多轮反馈”→ 德尔菲。
- 看到“因果关系、实验组/对照组”→ 实验法。
- 看到“无调查员偏差”→ 优先邮寄调查；看到“调查员不与对象接触”→ 优先观察法。

## 待核对

- `Q13-BK-015` 问“实施力控制程度最低”，题库答案给“入户面访”。常见教材表述中，邮寄调查的现场控制程度通常最低。建议按题库答案记忆，同时保留这一疑问。
- `Q13-BK-013` 把“前期观察对后期观察的影响”称为“主效应”，这是题库/教材的特定用法；标准实验设计里“主效应”指因素的主效应，两者不要混。
- 焦点小组成员数、时长在不同教材中略有差异，常见为 6—10 人、1.5—2 小时。
