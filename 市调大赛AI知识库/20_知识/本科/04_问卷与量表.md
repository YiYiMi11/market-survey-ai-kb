# 04 问卷与量表

> 对应第17届本科提纲第4章：问卷及量表的设计与应用。
> 本章题量 61，是概念最细、最容易出“表述错误”型选择题的章节。

## 一句话定位

问卷是结构化的数据采集工具；量表是测量态度/特征的工具。问卷设计解决“问什么、怎么问、怎么答、怎么编码”，量表设计解决“用什么尺度测、测得准不准”。

## 核心概念

### 1. 问卷的结构

| 部分 | 内容 | 作用 |
|---|---|---|
| 标题 | 调查主题 | 让被调查者快速了解调查 |
| 说明词 | 调查目的、保密承诺、填答说明、致谢 | 建立信任、指导填答 |
| 甄别部分 | 筛选符合条件的被调查者 | 确保样本符合要求（`Q17-BK-021`） |
| 主体/正文 | 问题陈述、备选答案、回答方式 | 收集核心数据（`Q12-BK-019`） |
| 背景信息 | 性别、年龄、收入、职业等 | 分组与统计控制 |
| 结束语 | 致谢、联系方式、后续安排 | 礼貌收尾 |
| 编码 | 题号、选项代码、变量名 | 便于录入与分析 |

> `Q14-BK-024`：问卷编码规则不适合放在说明词部分；说明词主要放致谢、填答说明、保密承诺等。
>
> `Q17-BK-026`：调查截止日期后回收的问卷应 **废弃**，不能录入使用。

### 2. 问题的类型

| 分类依据 | 类型 | 说明 |
|---|---|---|
| 回答方式 | 开放式 | 不提供答案，被调查者自由填写（`Q16-BK-018`） |
|  | 封闭式 | 提供固定选项，被调查者选择（`Q15-BK-018`） |
|  | 混合式 | 封闭选项 + 开放补充 |
| 内容 | 事实性问题 | 询问客观事实，如“您现在用什么牌子的洗衣粉”（`Q12-BK-012`） |
|  | 动机性问题 | 询问“为什么” |
|  | 态度性问题 | 询问评价、喜好、满意度 |
|  | 假设性问题 | 询问“如果……你会……” |
| 表述方式 | 直接表述 | 简单询问、假定、释疑（`Q12-BK-065`） |
|  | 间接表述 | 转移、情景（`Q16-BK-066`） |
| 数量 | 单项选择 | 只能选一个 |
|  | 多项选择 | 可选多个（`Q15-BK-025` 答案类型最多） |
|  | 排序/比较 | 对选项排序或两两比较 |

### 3. 问题表述的原则

- 具体、清晰、通俗，避免专业行话（`Q17-BK-022` 的 CPI 问句问题是不通俗易懂）。
- 避免双管问题（一个问句问两件事）。
- 避免诱导性、倾向性措辞（`Q12-BK-021` 的“奢侈行为”带有特殊语气）。
- 避免否定式、双重否定。
- 避免超出被调查者记忆能力的时间跨度（`Q13-BK-025` “经常”表述不清晰）。
- 避免敏感问题的直接询问，可用转移法、情景法、释疑法。
- 避免从众效应、权威效应。
- 适当使用释疑法消除顾虑（`Q12-BK-017`）。

### 4. 问题排列的原则

- 先易后难、先一般后具体。
- 先封闭后开放、先熟悉后陌生。
- 敏感问题、背景信息放在后面。
- 按逻辑顺序排列，避免顺序效应。
- 相邻问题的回答应尽量独立（`Q15-BK-022` 体现逻辑性原则）。
- 不是“所有问题必须随机排列”（`Q13-BK-021` 错误说法）。

### 5. 答案设计的原则

| 原则 | 含义 |
|---|---|
| 穷尽性 | 所有可能情况都有对应选项 |
| 互斥性 | 选项之间不交叉、不重叠 |
| 通俗性 | 选项表述易懂 |
| 中立性 | 选项不诱导 |
| 简洁性 | 选项数量适当、文字简短 |
| 有序性 | 有顺序关系的选项按顺序排列 |

> `Q16-BK-021`：不属于答案设计原则的是 **中立性**（题库口径；中立性更像问题表述原则）。
>
> 组距分组要遵循“上限不计入”原则（`Q12-BK-080`）。例如 3000 元归入“3000—5000 元”，不归入“1000—3000 元”（`Q16-BK-032`）。

### 6. 测量尺度

| 尺度 | 特征 | 可做运算 | 典型例子 | 集中趋势 |
|---|---|---|---|---|
| 定类（名义） | 分类，无顺序 | 频数、百分比 | 性别、品牌、婚姻状况 | 众数 |
| 定序（顺序） | 有顺序，但间距不等 | 比较大小、排序 | 学历、收入等级、满意度等级 | 中位数、众数 |
| 定距（等距） | 有相等单位，无绝对零点 | 加减 | 摄氏温度、百分制评分 | 均值、标准差 |
| 定比（比率） | 有相等单位，有绝对零点 | 加减乘除 | 身高、体重、收入、年龄 | 均值、标准差、变异系数 |

关键结论：

- 有绝对零点 → 定比量表（`Q13-BK-022`）。
- 适用于任何统计分析方法 → 定比量表（`Q13-BK-023`）。
- 客观事实性数值型数据 → 定比量表（`Q12-BK-016`）。
- 身高是定比数据（`Q16-BK-025`）。
- 定类数据的位置集中趋势用众数（`Q13-BK-032`）。
- 高计量层次可转化为低层次，低层次不能上升为高层次（`Q13-BK-066`）。
- 年龄既可用定距（具体岁数）也可用定比（年龄有绝对零点）测量；分组年龄是定序（`Q17-BK-066`）。
- 收入既可按数值型分析，也可按顺序变量分析（`Q15-BK-034`）。

### 7. 量表类型

| 量表 | 做法 | 适用 | 注意 |
|---|---|---|---|
| 李克特量表 | 一组陈述，5/7 级同意程度 | 态度、意见 | 需检验内部一致性 |
| 语义差别量表 | 一对反义形容词，数轴评分 | 品牌/企业形象 | 两端词必须真正对立（`Q17-BK-024`） |
| 评比量表 | 直接打分/等级评价 | 满意度、偏好 | 可能产生中间倾向误差（`Q14-BK-021`） |
| 排序量表 | 对对象排序 | 品牌偏好、重要性 | 不能反映差距大小 |
| 配对比较量表 | 两两比较 | 少量对象的偏好 | 比较次数多、不能测绝对差距（`Q12-BK-064`） |
| 等级顺序量表 | 按等级排列 | 偏好、重要性 | 顺序数据 |
| 表式量表 | 用表格呈现 | 多项目评价 | 提高回答效率（`Q13-BK-066`） |

> `Q14-BK-019`：连锁超市形象调查 → 语义差别量表。
>
> `Q12-BK-022`：品牌偏好调查 → 比较法（题库口径）。
>
> `Q15-BK-024`：4 个品牌按偏好排序 → 比较法（题库口径；若强调直接排序，也可能用排序法，见“待核对”）。

### 8. 信度与效度

| 概念 | 含义 | 类型 |
|---|---|---|
| 信度 | 测量结果的稳定性、一致性、可靠性 | 再测信度、复本信度、分半信度、内部一致性信度 |
| 效度 | 测量结果是否测到了要测的东西 | 内容效度、效标效度、结构效度 |

- 再测信度：同一组人前后两次测量，求两次结果的相关系数（`Q14-BK-023` 题干描述的是再测信度，但题库答案给内部一致性，见“待核对”）。
- 复本信度：两个平行量表测量同一对象。
- 分半信度：量表题目分成两半，求两半得分的相关。
- 内部一致性：Cronbach's α，衡量题目之间的同质性。
- 内容效度：题目是否覆盖了概念的全部内容。
- 效标效度：测量结果与外部效标的相关程度。
- 结构效度：测量结果与理论构念的对应程度，是效度的最高层次（`Q15-BK-078`、`Q16-BK-023`）。
- 信度是效度的必要条件，但不是充分条件；信度高不一定效度高。

### 9. 问卷编码

| 类型 | 适用 | 说明 |
|---|---|---|
| 预编码（事前编码） | 封闭式问题 | 设计问卷时就给每个选项分配代码 |
| 后编码（事后编码） | 开放式问题 | 回收问卷后，对回答归类再编码（`Q16-BK-024`、`Q17-BK-030`） |
| 顺序编码 | 有序分类 | 如收入分组 1—4（`Q12-BK-023`、`Q17-BK-029`） |

### 10. 问卷测试与质量评价

- 预调查/试填：检验问卷长度、措辞、逻辑、选项、编码。
- 问卷测试样本量：经验上一般为问卷题量的 **5—10 倍**（`Q12-BK-018`）。
- 量表设计出来后要加以质量评价，不能直接大规模使用（`Q17-BK-023`）。
- 一份好问卷：对被调查者友好、能准确收集数据、逻辑清晰、长度适当（`Q16-BK-022`）。
- 问卷要准确反映客观事物的特征或属性，体现 **有效性**（`Q12-BK-020`）。
- 问卷是获取数据的一种有序的、**结构化**的方法（`Q17-BK-025`）。

## 常考结论

1. 问卷正文 = 问题陈述 + 备选答案 + 回答方式。
2. 甄别部分的作用是确保被调查者符合要求。
3. 开放式问题用后编码；封闭式问题用预编码。
4. 定类→众数；定序→中位数；定距/定比→均值。
5. 有绝对零点 → 定比；有相等单位无绝对零点 → 定距。
6. 语义差别量表用于形象/态度；李克特用于同意程度；配对比较用于两两偏好。
7. 信度看稳定性，效度看准确性；结构效度是效度最高层次。
8. 量表设计后要质量评价；问卷测试样本量约为题量 5—10 倍。
9. 调查截止后回收的问卷应废弃。

## 易混点

| A | B | 区别 |
|---|---|---|
| 问卷 | 量表 | 问卷是采集工具；量表是测量工具，可由多个题项组成 |
| 定距 | 定比 | 定距无绝对零点，定比有绝对零点 |
| 定类 | 定序 | 定类无顺序，定序有顺序 |
| 开放式 | 封闭式 | 自由填答 vs 固定选项 |
| 事实性问题 | 态度性问题 | 问客观事实 vs 问评价/感受 |
| 直接表述 | 间接表述 | 直接问 vs 转移/情景/投影 |
| 预编码 | 后编码 | 事前设计代码 vs 事后归类编码 |
| 信度 | 效度 | 稳不稳定 vs 准不准 |
| 再测信度 | 内部一致性 | 前后两次测量相关 vs 题目间同质性 |
| 内容效度 | 结构效度 | 覆盖内容 vs 对应理论构念 |
| 排序法 | 比较法 | 直接排序 vs 两两比较后排序 |
| 中间倾向误差 | 仁慈误差 | 不愿给极端评价 vs 倾向于给好评 |

## 答题套路

- 看到“客观事实、数值型”→ 定比。
- 看到“分类/品牌/性别”→ 定类。
- 看到“学历/满意度等级/收入分组”→ 定序。
- 看到“温度/百分制评分”→ 定距（但题库把气温资料答成比率尺度，见“待核对”）。
- 看到“绝对零点”→ 定比。
- 看到“固定选项”→ 封闭式。
- 看到“自由填写”→ 开放式。
- 看到“前后两次测量相关”→ 再测信度。
- 看到“题目间一致性”→ 内部一致性。
- 看到“理论构念对应程度”→ 结构效度。
- 看到“问卷测试样本量”→ 题量 5—10 倍。
- 看到“截止日期后回收”→ 废弃。

## 待核对

- `Q17-BK-006`：问“全球各大都市的气温资料”的测度尺度，题库答案给 **比率尺度**。按标准测量理论，摄氏/华氏温度只有相等单位、没有绝对零点，应为 **定距尺度**；只有开尔文温度才是定比。考试按题库答案，但建议保留疑问。
- `Q14-BK-023`：题干“对同一组人员进行前后两次测量，所得两组测量结果之间的相关系数”标准答案是 **再测信度**；题库答案给 **内部一致性信度**。选项 A 写作“再测效信度”（疑似“再测信度”笔误）。建议按题干理解，考试时留意选项原文。
- `Q15-BK-024`：4 个品牌按偏好程度排序，题库答案给 **比较法**；若题目强调直接排序，教材也可能给 **排序法**。按题库答案记，同时理解两种方法的差别。
- `Q16-BK-021`：题库认为“中立性”不属于答案设计原则；部分教材会把中立性列为问题表述/答案设计的一般原则。按题库答案记。
