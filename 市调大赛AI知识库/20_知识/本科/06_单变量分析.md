# 06 单变量分析

> 对应第17届本科提纲第6章：规模、结构与比较分析；集中度分析；差异性分析；参数估计；显著性检验。
> 本章题量 62，是统计公式最密集的一章。考试重点是“指标选择 + 公式条件 + 两类错误”。

## 一句话定位

单变量分析回答三类问题：**数据长什么样**（分布）、**总体参数是多少**（估计）、**关于总体的判断是否成立**（检验）。

## 核心概念

### 1. 统计基础

| 概念 | 含义 |
|---|---|
| 总体 | 研究对象的全体 |
| 样本 | 从总体中抽取的部分单位 |
| 参数 | 描述总体特征的数字，如 μ、σ、π |
| 统计量 | 描述样本特征的数字，如 x̄、s、p |
| 抽样分布 | 统计量的概率分布 |
| 标准误 | 统计量的标准差，如 σ/√n |

> `Q13-BK-080`：描述总体特征的概括性数字度量称为 **参数**。
>
> `Q16-BK-070`：样本均值、样本比例是总体均值的无偏估计；样本方差是总体方差的无偏估计；样本标准差不是总体标准差的无偏估计。
>
> `Q12-BK-041`：估计量的数学期望等于被估参数 → **无偏估计量**。

估计量的四个性质：

| 性质 | 含义 |
|---|---|
| 无偏性 | E(θ̂)=θ |
| 有效性 | 在无偏估计中方差更小 |
| 一致性 | n→∞ 时 θ̂ 依概率收敛于 θ |
| 充分性 | 估计量利用了样本中的全部相关信息 |

### 2. 集中趋势

| 指标 | 公式/定义 | 适用 | 对极端值 |
|---|---|---|---|
| 均值 x̄ | Σx/n | 定距/定比，分布较对称 | 敏感 |
| 中位数 Me | 排序后中间位置 | 定序及以上，偏态分布 | 稳健 |
| 众数 Mo | 出现次数最多的值 | 定类及以上 | 稳健 |
| 几何平均数 | (Πx)^(1/n) | 平均增长率、比率 | 稳健 |
| 调和平均数 | n/Σ(1/x) | 平均速度、平均价格 | 较稳健 |

偏态分布的经验关系：

- 右偏（正偏）：均值 > 中位数 > 众数（`Q13-BK-033`、`Q17-ZK-049`）。
- 左偏（负偏）：均值 < 中位数 < 众数。
- 对称：均值 ≈ 中位数 ≈ 众数。
- 极端值或严重偏态时，中位数/众数比均值更能代表集中趋势（`Q12-BK-029`、`Q14-BK-031`）。

> 记忆：**均值追尾巴**。尾巴在右，均值被拉向右；尾巴在左，均值被拉向左。

### 3. 离散程度

| 指标 | 公式 | 特点 |
|---|---|---|
| 极差 R | max-min | 简单，只受两端值影响 |
| 四分位距 IQR | Q3-Q1 | 稳健，忽略两端 25% |
| 方差 s² | Σ(x-x̄)²/(n-1) | 单位平方，不直观 |
| 标准差 s | √s² | 与原数据同单位 |
| 变异系数 CV | s/x̄ ×100% | 无量纲，可比较不同均值/单位 |
| 标准分数 z | (x-x̄)/s | 标准化，均值 0、标准差 1 |

> `Q16-BK-036`：方差 25，均值 10 → 标准差 5，离散系数 = 5/10 = 0.5。
>
> `Q13-BK-031 / Q17-BK-031`：两组均值不同、标准差相同，比较相对差异要用变异系数；均值越小，变异系数越大。
>
> `Q12-BK-070`：有放回简单随机抽样，样本量变为 4 倍，样本均值标准差变为原来的 1/2，置信区间宽度也变为 1/2。

### 4. 分布形态

| 指标 | 含义 | 判断 |
|---|---|---|
| 偏态系数 | 分布不对称程度 | >0 右偏，<0 左偏，=0 对称 |
| 峰度 | 分布尖峭/平坦程度 | 正态峰度约为 3（超额峰度为 0） |
| 箱线图 | 中位数、Q1、Q3、须、离群点 | 中位数到 Q1 的距离 > 到 Q3 的距离 → 左偏 |

> `Q17-BK-036`：Q1=45，Me=85，Q3=105。下半部分跨度 40，上半部分跨度 20，左侧尾部更长 → **左偏**。
>
> `Q17-BK-035`：经验法则：±1σ ≈ 68%，±2σ ≈ 95%，±3σ ≈ 99.7%。区间 [-3,3] 对应约 0.99。

### 5. 参数估计

**点估计**：用样本统计量直接估计总体参数。

**区间估计**：在置信度 1-α 下，给出参数的一个区间。

| 估计对象 | 条件 | 置信区间 |
|---|---|---|
| 总体均值 μ | σ 已知，正态总体或大样本 | x̄ ± z_(α/2) · σ/√n |
| 总体均值 μ | σ 未知，正态总体 | x̄ ± t_(α/2,n-1) · s/√n |
| 总体比例 π | np≥5, n(1-p)≥5 | p ± z_(α/2) · √(p(1-p)/n) |
| 总体方差 σ² | 正态总体 | [(n-1)s²/χ²_(α/2), (n-1)s²/χ²_(1-α/2)] |

样本量公式：

- 均值：n = (z_(α/2)·σ / E)²；有限总体修正 n = n0 / (1 + n0/N)。
- 比例：n = z²_(α/2)·p(1-p) / E²；p 未知取 0.5，使方差最大、样本量最保守。
- 考虑设计效应：n = deff · n_srs。
- 考虑回答率：最终样本量 = 计算样本量 / 预计回答率。

> `Q12-BK-037`：初始样本量 400，回答率 65% → 最终样本量 = 400/0.65 ≈ 615。
>
> `Q17-BK-037`：总体比例未知取 0.5。
>
> `Q15-BK-038`：若公式直接使用方差 p(1-p)，则取 0.25；若公式使用比例 p，则取 0.5。看清题目问的是“比例”还是“变异程度/方差”。

置信区间与精度的关系：

- 置信度越高 → 临界值越大 → 区间越宽 → 精度越低。
- 样本量越大 → 标准误越小 → 区间越窄 → 精度越高。
- `Q13-BK-039 / Q16-BK-038`：抽样方式与样本量不变，置信区间越大 → 置信度越高。
- `Q16-BK-080`：其他条件不变，置信度越高，置信区间越宽。
- `Q16-BK-082`：其他条件不变，抽样单位数越多，抽样误差越小（题干说越大，故错）。

### 6. 假设检验

基本步骤：

1. 提出原假设 H0 和备择假设 H1。
2. 选择检验统计量，确定其分布。
3. 给定显著性水平 α，确定拒绝域/临界值。
4. 计算统计量或 p 值。
5. 作出决策：拒绝 H0 或不能拒绝 H0。
6. 解释结论（统计显著 ≠ 实际重要）。

两类错误：

| 情形 | H0 为真 | H0 为假 |
|---|---|---|
| 拒绝 H0 | 第一类错误（弃真），概率 α | 正确（功效 1-β） |
| 不拒绝 H0 | 正确 | 第二类错误（取伪），概率 β |

> `Q14-BK-047`：第二类错误是原假设错误时没有拒绝原假设，即“取伪”。
>
> `Q16-BK-034`：增大样本容量，通常两类错误的概率都减小，检验功效提高。

单侧 vs 双侧：

- 双侧：H1: μ≠μ0，临界值 z_(α/2)。
- 右侧：H1: μ>μ0，临界值 z_α；用于“是否提高/增加”。
- 左侧：H1: μ<μ0，临界值 -z_α；用于“是否降低/减少”。

> `Q17-BK-068`：判断寿命是否“明显提高” → 右侧检验 H1: μ>100；σ 已知用 Z 统计量；z=(102-100)/(10/√100)=2 > 1.645，拒绝 H0。

常见检验：

| 检验 | 用途 | 统计量 |
|---|---|---|
| 单样本 Z 检验 | 均值，σ 已知 | z=(x̄-μ0)/(σ/√n) |
| 单样本 t 检验 | 均值，σ 未知 | t=(x̄-μ0)/(s/√n)，df=n-1 |
| 独立样本 t 检验 | 两均值比较 | t=(x̄1-x̄2)/√(s1²/n1+s2²/n2) |
| 配对 t 检验 | 配对差值均值 | t=d̄/(s_d/√n)，df=n-1 |
| 卡方检验 | 方差、列联表 | χ²=Σ(O-E)²/E |
| F 检验 | 两方差比、方差分析 | F=s1²/s2² 或 MSA/MSE |

> `Q17-BK-033`：检验一个正态总体方差用 χ² 分布；检验两个总体方差是否相等用 F 分布。
>
> `Q17-BK-041`：两正态总体方差是否相等 → F 检验。
>
> `Q17-BK-054`：一元线性回归中，对回归系数 β=0 的检验，t 检验、F 检验、相关系数检验三者等价。

### 7. 时间序列与统计指数（简要）

- 时间序列构成：长期趋势 T、季节变动 S、循环变动 C、不规则变动 I。
- 平稳序列预测：移动平均、简单平均、指数平滑（`Q15-BK-068`）。
- 逐期增长量大体相等 → 直线趋势模型，不是二次曲线（`Q15-BK-080` 答案：错）。
- 季节指数以 100%（或 1）为基准；无季节变动时各期季节指数等于 1（`Q16-BK-035`）。
- 销售额指数 = 价格指数 × 销售量指数。销售额增长 5%、价格增长 2% → 销售量增长 = 1.05/1.02 - 1 ≈ 2.94%（`Q14-BK-036`）。

## 常考结论

1. 参数对应总体，统计量对应样本。
2. 无偏看期望，有效看方差，一致看样本量趋于无穷。
3. 偏态分布：均值追尾巴；右偏均值最大，左偏均值最小。
4. 比较不同均值/单位的离散程度用变异系数。
5. σ 已知用 Z，σ 未知用 t；一个方差用 χ²，两个方差比用 F。
6. 置信度越高，区间越宽，精度越低。
7. 样本量增大，标准误减小，两类错误通常都减小。
8. 第一类错误弃真，第二类错误取伪；功效 = 1-β。
9. 比例未知取 0.5；方差 p(1-p) 最大为 0.25。
10. 回归系数检验、相关系数检验、F 检验在一元回归中等价。

## 易混点

| A | B | 区别 |
|---|---|---|
| 标准差 | 标准误 | 个体离散程度 vs 统计量的抽样波动 |
| 参数 | 统计量 | 总体 vs 样本 |
| 置信度 | 置信区间 | 可靠程度 vs 区间范围 |
| 第一类错误 | 第二类错误 | 弃真 vs 取伪 |
| 单侧检验 | 双侧检验 | 有方向 vs 无方向 |
| 方差 | 变异系数 | 有单位 vs 无量纲 |
| 偏态 | 峰度 | 不对称程度 vs 尖峭程度 |
| 样本方差分母 n-1 | 总体方差分母 N | 无偏估计 vs 总体定义 |

## 答题套路

- 看到“总体特征数字”→ 参数；看到“样本特征数字”→ 统计量。
- 看到“期望等于参数”→ 无偏；看到“方差最小”→ 有效；看到“n→∞收敛”→ 一致。
- 看到“右偏/正偏”→ 均值 > 中位数 > 众数。
- 看到“不同均值比离散”→ 变异系数。
- 看到“σ 已知”→ Z；看到“σ 未知”→ t。
- 看到“一个方差”→ χ²；看到“两个方差比/方差齐性”→ F。
- 看到“提高/增加/是否明显”→ 右侧检验；看到“降低/减少”→ 左侧检验。
- 看到“置信度提高”→ 区间变宽；看到“样本量增加”→ 区间变窄。
- 看到“比例未知”→ 0.5；看到“方差/变异程度”→ 0.25。

## 待核对

- `Q15-BK-038`：题干问“总体变异程度”的取值，答案 0.25 对应的是方差 p(1-p)；若直接问“总体比例”，标准答案是 0.5。两者不要混。
- 偏态分布下均值、中位数、众数的严格排序会受分布形态影响，考试通常按“右偏均值最大、左偏均值最小”的通用结论作答。
- 峰度有“原始峰度”和“超额峰度”两种口径，考试看清题干。
