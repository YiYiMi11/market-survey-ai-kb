# 08 双变量关联分析

> 对应第17届本科提纲第8章：双变量列联分析、双变量相关分析、双变量回归分析。
> 本章题量 50，核心是“三类分析各管什么 + 公式 + 显著性检验”。

## 一句话定位

双变量分析回答：两个变量**有没有关系**（列联/相关）、**关系有多强**（相关系数）、**怎么用另一个变量解释/预测**（回归）。

## 核心概念

### 1. 列联分析

- 对象：两个分类变量（定类/定序）。
- 工具：列联表（交叉表）。
- 检验：独立性检验、一致性检验、拟合优度检验，均基于 χ² 分布。
- 期望频数：E_ij = (行合计×列合计)/总合计。
- χ² 统计量：χ² = Σ(O_ij-E_ij)²/E_ij。
- 自由度：df=(r-1)(c-1)。
- 关联系数：φ、C、Cramér's V。

| 检验 | 目的 |
|---|---|
| 独立性检验 | 两个分类变量在总体中是否独立 |
| 一致性检验 | 两个配对/重复分类结果是否一致 |
| 拟合优度检验 | 样本分布是否符合某理论分布 |

> `Q12-BK-049`：独立性检验和一致性检验均采用 **χ² 检验**。
>
> `Q15-BK-054`：拟合优度检验用 **χ² 分布**。
>
> `Q13-BK-083`：3×2 列联表，df=(3-1)(2-1)=2；题干说 6 → 错。
>
> `Q15-BK-051`：5×6 列联表，df=(5-1)(6-1)=20。
>
> `Q13-BK-054`：|φ|=1 → 两个变量完全相关。
>
> `Q16-BK-053`：列联表行/列变量的指定，有因果时一般自变量作行、因变量作列；题干说“可随意指定” → 错（题库答案 D）。

列联分析注意：

- χ² 检验拒绝 H0 只说明“存在关联”，不说明关联强弱，也不说明因果。
- χ² 值受样本量影响，样本很大时微小差异也可能显著。
- 列联分析用于分类变量；数值型变量用相关/回归。
- `Q14-BK-083`：列联分析用于两个数值型变量 → 错，应为分类变量。
- `Q12-BK-083`：研究两个品质型变量之间的关系，一般采用列联分析 → 对。

### 2. 相关分析

- 对象：两个数值型变量（或定序变量用 Spearman）。
- 工具：散点图、相关系数。
- Pearson 相关系数 r：
  r = Cov(X,Y)/(s_X·s_Y)
  r = [nΣxy-ΣxΣy] / √{[nΣx²-(Σx)²][nΣy²-(Σy)²]}
- 取值范围：-1 ≤ r ≤ 1。
- r>0 正相关，r<0 负相关，r=0 线性无关。
- |r| 越大，线性相关越强；但 r=0 不代表完全无关（可能存在非线性关系）。
- 显著性检验：H0: ρ=0，t = r√(n-2)/√(1-r²)，df=n-2。

> `Q12-BK-051`：现象之间的相互关系可归纳为 **相关关系与函数关系** 两种类型。
>
> `Q12-BK-053`：相关分析不要求变量有因果关系；回归分析通常要区分自变量/因变量。
>
> `Q14-BK-052 / Q16-BK-054`：样本 r=0.32，n 未知，不能直接判断总体相关；需要显著性检验，且相关不等于因果。
>
> `Q17-BK-083`：相关关系按方向分为正相关和负相关，不是线性/非线性；按形式才分线性/非线性 → 题干错。

相关程度经验判断（仅供参考）：

| |r| | 程度 |
|---|---|---|
| 0—0.3 | 弱相关 |
| 0.3—0.5 | 低度相关 |
| 0.5—0.8 | 中度相关 |
| 0.8—1.0 | 强相关 |

> 不同教材分界略有差异，考试以选项表述为准。

### 3. 一元线性回归

模型：Y = a + bX + ε。

- b：斜率/回归系数，表示 X 每增加 1 单位，Y 平均改变 b 单位。
- a：截距，X=0 时 Y 的期望值。
- 最小二乘估计：使残差平方和 SSE=Σ(y-ŷ)² 最小。
- b = Σ(x-x̄)(y-ȳ)/Σ(x-x̄)²。
- a = ȳ - b·x̄。
- 判定系数 R² = SSR/SST = 1-SSE/SST，表示回归方程解释的变异比例。
- 估计标准误差 Se = √(SSE/(n-2))。
- 回归系数标准误 Sb，t = b/Sb，df=n-2。
- F = MSR/MSE = (SSR/1)/(SSE/(n-2))，与 t 检验等价。
- 预测：点预测 ŷ0 = a+bx0；区间预测考虑个别值波动，比均值置信区间更宽。

> `Q12-BK-050`：b<0 → X 增加，Y 平均减少，负相关。
>
> `Q12-BK-052`：ŷ=63+152x，价格每提高 1 元，供应量平均增加 152 件。
>
> `Q13-BK-053 / Q17-BK-053`：ŷ=3-2x，R²=0.81 → |r|=0.9，斜率为负 → r=-0.9。
>
> `Q14-BK-054 / Q15-BK-055`：SSE=100，n=27 → Se²=SSE/(n-2)=100/25=4。
>
> `Q15-BK-071 / Q13-BK-072`：最小二乘使残差平方和最小。
>
> `Q14-BK-071`：估计标准误差为 0 → 所有观测点都在回归线上，R²=1。
>
> `Q12-BK-069`：估计标准误差越小，回归方程拟合越好；Se 与 Y 同单位；Se=0 表示完全拟合。

回归假定：

1. 线性关系：E(Y)=a+bX。
2. 误差项零均值。
3. 同方差：Var(ε)=σ²。
4. 误差项相互独立。
5. 误差项服从正态分布。
6. 自变量之间无多重共线性（多元回归）。

> `Q13-BK-071`：误差项假定包括零均值、同方差、独立、正态；不包括“不同 x 下方差不同”。
>
> `Q17-BK-056`：多元回归假定中“随机误差项异方差”是错误说法。
>
> `Q15-BK-072`：残差基本假定包括零均值、同方差、独立、正态。

### 4. 回归诊断

| 诊断 | 方法 | 关注 |
|---|---|---|
| 线性 | 残差图、成分残差图 | 是否有弯曲模式 |
| 同方差 | 残差-拟合值图、Spearman 秩相关 | 是否漏斗形 |
| 正态性 | 正态概率图 Q-Q 图 | 点是否沿对角线 |
| 独立性 | DW 统计量、残差图 | 是否序列相关 |
| 异常值/强影响点 | 标准化残差、Cook 距离、杠杆值 | 是否影响估计 |
| 多重共线性 | VIF、条件指数 | VIF 是否过大 |

DW 统计量：

- 取值 0—4。
- DW≈2：无一阶自相关。
- DW≈0：正自相关（ρ≈1）。
- DW≈4：负自相关（ρ≈-1）。

> `Q13-BK-056`：DW 接近 0 表示负相关 → 错，应为正自相关。
>
> `Q16-BK-051`：正态概率图中点密集分布在对角线附近 → 残差正态。
>
> `Q16-BK-083`：Spearman 秩相关系数可用于检验残差绝对值与拟合值的相关性，辅助判断异方差 → 对。
>
> `Q16-BK-084`：VIF 接近于 0 表明严重多重共线性 → 错；VIF 大才是共线性严重。
>
> `Q17-BK-055`：残差分析中不能用来分析模型假定的方法要结合选项判断；残差图、正态概率图、DW 都可。

### 5. 相关与回归的区别

| 维度 | 相关分析 | 回归分析 |
|---|---|---|
| 目的 | 测度关系强度与方向 | 建立模型、解释/预测 |
| 变量地位 | 对等 | 区分自变量/因变量 |
| 是否要求因果 | 不要求 | 通常假设因果方向 |
| 输出 | 相关系数 r | 回归方程、R²、系数检验 |
| 适用范围 | 双变量 | 一元/多元 |

> `Q12-BK-053`：相关分析研究变量间相关关系，回归分析研究依赖关系；相关不要求因果，回归通常有方向。
>
> `Q17-BK-052`：有因果关系的现象做回归，要注意因果方向、遗漏变量、模型设定。

### 6. 列联分析、相关分析、回归分析的选择

| 变量类型 | 分析 |
|---|---|
| 两个分类变量 | 列联分析（χ²） |
| 两个数值变量 | 相关分析、回归分析 |
| 一个分类 + 一个数值 | 方差分析（多组均值比较） |
| 多个数值自变量 + 一个数值因变量 | 多元回归 |
| 多个数值自变量 + 一个二分类因变量 | Logistic 回归 |

## 常考结论

1. 列联分析用于分类变量；χ² 自由度 (r-1)(c-1)。
2. χ² 显著只说明有关联，不说明强弱、不说明因果。
3. r 范围 -1 到 1；|r| 越大线性相关越强；r=0 不代表无关。
4. 相关不要求因果；回归区分自变量/因变量。
5. 最小二乘使残差平方和最小。
6. R² 表示解释的变异比例；R² 开方只给 |r|，符号看回归系数。
7. 一元回归误差方差无偏估计 = SSE/(n-2)。
8. 回归系数检验、F 检验、相关系数检验在一元回归中等价。
9. DW≈2 无自相关；DW≈0 正自相关；DW≈4 负自相关。
10. VIF 越大，多重共线性越严重。
11. 相关不等于因果。

## 易混点

| A | B | 区别 |
|---|---|---|
| 相关分析 | 回归分析 | 对等关系 vs 依赖关系 |
| r | R² | 相关方向与强度 vs 解释比例 |
| 判定系数 | 调整判定系数 | 未惩罚变量数 vs 惩罚变量数 |
| 列联分析 | 方差分析 | 两个分类变量 vs 分类+数值 |
| 独立性检验 | 拟合优度检验 | 两变量独立 vs 分布拟合 |
| DW 接近 0 | DW 接近 4 | 正自相关 vs 负自相关 |
| 残差 | 误差项 | 样本残差 vs 总体不可观测误差 |
| 置信区间 | 预测区间 | 均值响应 vs 个别值响应 |

## 答题套路

- 看到“两个分类变量”→ 列联分析/χ²。
- 看到“两个数值变量”→ 相关/回归。
- 看到“自由度”→ (r-1)(c-1)。
- 看到“|φ|=1”→ 完全相关。
- 看到“r 的符号”→ 看回归系数或协方差。
- 看到“R²=0.81”→ |r|=0.9，符号看 b。
- 看到“SSE/(n-2)”→ 误差方差无偏估计。
- 看到“最小二乘”→ 残差平方和最小。
- 看到“DW≈0”→ 正自相关；“DW≈4”→ 负自相关。
- 看到“VIF 大”→ 多重共线性严重。
- 看到“相关等于因果”→ 错。
