# 07 抽样估计

> 对应第17届本科提纲第7章：抽样设计；抽样估计。
> 本章题量 115，是全库最大章节，也是重复题、易错题最集中的章节。重点：**抽样方法识别、误差类型、样本量、估计量性质**。

## 一句话定位

抽样估计用样本推断总体。核心是三件事：**怎么抽**（抽样设计）、**怎么估**（估计量）、**估得准不准**（误差与样本量）。

## 核心概念

### 1. 抽样基础

| 概念 | 含义 |
|---|---|
| 目标总体 | 研究者真正想推断的总体 |
| 抽样总体 | 实际抽样框所覆盖的总体 |
| 抽样框 | 抽样单元的名录/名单/地图，如学生名册、住户地图 |
| 抽样单元 | 抽样时被抽取的基本单位 |
| 入样概率 | 每个单元被抽中的概率 |
| 抽样比 f | n/N |
| 抽样误差 | 随机抽样产生的代表性误差 |
| 非抽样误差 | 抽样误差以外的误差：抽样框、无回答、计量、记录、录入等 |

> `Q14-BK-045 / Q15-BK-048 / Q16-BK-047`：抽样误差是 **随机抽样而产生的代表性误差**。
>
> `Q12-BK-014`：回答记录与真值不同 → **计量误差**。
>
> `Q17-BK-049`：样本估计值与总体真实指标值之间的差距 → **调查误差（总误差）**，包含抽样误差和非抽样误差。

### 2. 概率抽样 vs 非概率抽样

| 维度 | 概率抽样 | 非概率抽样 |
|---|---|---|
| 入样概率 | 已知且非零 | 未知 |
| 抽样误差 | 可以计算 | 不能计算 |
| 推断总体 | 可以概率推断 | 一般不能概率推断 |
| 典型方法 | 简单随机、分层、系统、整群、多阶段、二重 | 配额、判断、便利、自愿、滚雪球 |
| 优点 | 代表性强、可推断 | 快速、低成本、适合探索 |
| 缺点 | 成本高、需要抽样框 | 偏差难控制、不能外推 |

> `Q14-BK-077`：无论概率抽样还是非概率抽样都可以计算抽样误差 → **错**。
>
> `Q14-BK-080`：只有概率抽样才能推断总体 → 对（题库口径）。
>
> `Q15-BK-008`：非概率抽样的错误叙述要结合选项判断；核心是“不能计算抽样误差”。

### 3. 简单随机抽样（SRS）

- 定义：从总体中按等概率、独立地抽取 n 个单位。
- 有放回：每次抽后放回，样本单位可能重复。
- 无放回：每次抽后不放回，样本单位不重复。
- 均值估计：ȳ = Σy/n。
- 方差（无放回）：V(ȳ) = (1-f)·S²/n，其中 f=n/N。
- 标准差（标准误）：SE(ȳ) = √[(1-f)·S²/n]。
- 比例估计：p = m/n；V(p) ≈ (1-f)·p(1-p)/n。

> `Q12-BK-039`：简单随机抽样又称 **纯随机抽样**。
>
> `Q16-BK-040`：简单随机抽样的设计效应 = 1。
>
> `Q16-BK-069`：简单随机抽样适合总体规模不大、分布较均匀、有完整抽样框的情形。

### 4. 分层抽样

- 做法：先把总体按某标志分成若干层，再从每层独立抽取样本。
- 条件：**层内同质、层间异质**。
- 优点：精度高、可分别推断各层、便于组织。
- 估计量：ȳ_st = Σ W_h·ȳ_h，W_h=N_h/N。
- 方差：V(ȳ_st) = Σ W_h²·(1-f_h)·S_h²/n_h。
- 样本量分配：
  - 比例分配：n_h = n·N_h/N。
  - 奈曼分配：n_h ∝ N_h·S_h。
  - 最优分配：n_h ∝ N_h·S_h/√c_h。
- `Q16-BK-050`：分层抽样样本量分配一般不考虑 **常数分配**。

> `Q16-BK-046 / Q14-BK-044`：总体内部差异大 → 分层抽样。
>
> `Q12-BK-045`：比例分层抽样中，按总体大小比例分配与按平方根比例分配，层估计值的精度不同；平方根分配通常不是最优。

### 5. 系统抽样（等距抽样）

- 做法：总体排序后，按固定间隔 k=N/n 抽取。
- 优点：操作简单、样本分布均匀、适合连续生产/流水线。
- 风险：如果抽样间隔与总体周期性一致，会产生系统偏差（`Q12-BK-081`）。
- 示例：每隔半小时抽一次产品（`Q15-BK-039`、`Q17-BK-040`）；每 150 本存折抽一本（`Q15-BK-045`）；每 100 份报账单抽一份（`Q17-BK-046`）。

### 6. 整群抽样

- 做法：把总体分成若干群，随机抽取群，调查群内全部单位。
- 条件：**群内差异大、群间差异小**（群像总体的缩影）。
- 优点：抽样框要求低、实施方便、成本低。
- 缺点：精度通常低于简单随机抽样，设计效应 >1。
- `Q15-BK-081`：题干说“群内差异尽可能小、群间差异尽可能大” → **错**，说反了。

### 7. 多阶段抽样

- 做法：分阶段抽取抽样单元，如先抽班级，再抽学生。
- 与整群抽样区别：整群抽样抽中群后调查群内全部单位；多阶段抽样还要继续抽次级单元。
- `Q16-BK-045`：先抽 40 个班级，再从每班抽 10 名学生 → 多阶段抽样。
- `Q16-BK-081`：多阶段抽样不是“不同阶段采用不同抽样组织形式”的定义；它指分阶段抽取单元。
- `Q14-BK-048`：多阶抽样第一阶段抽学院，要兼顾可行性与效率。

### 8. 二重抽样（双重抽样）

- 做法：先抽一个大样本，用于筛查/获取辅助信息；再从中抽一个小样本，进行详细调查。
- 适用：稀有子群、需要辅助信息分层、筛查成本高。
- 与二阶抽样区别：二重抽样是“两次抽取、两次筛选”，二阶抽样是“分阶段抽单位”。

> `Q13-BK-042 / Q15-BK-046`：先抽大样本筛查高血压人群，再抽小样本详细检查 → **二重抽样**。

### 9. 非概率抽样

| 方法 | 做法 | 适用 | 局限 |
|---|---|---|---|
| 配额抽样 | 按特征分配名额，非随机选取 | 快速市场调查 | 不能计算抽样误差 |
| 判断抽样 | 研究者主观选择“有代表性”的单位 | 专家调查、试点 | 主观偏差 |
| 便利抽样 | 就近、方便地选取 | 探索性研究 | 代表性差 |
| 自愿抽样 | 自愿参与/自愿填答 | 网络调查、热线 | 自选择偏差 |
| 滚雪球抽样 | 由被调查者推荐下一个 | 稀有群体 | 样本偏差、网络依赖 |

> `Q15-BK-050 / Q17-BK-050`：网站主页有奖问卷 → **自愿抽样**。
>
> `Q17-BK-047`：配额抽样的优势是能保证样本结构、实施方便、成本较低。
>
> `Q13-BK-081`：滚雪球抽样适用于特征稀少的群体 → 对。

### 10. 抽样框误差

| 表现 | 说明 |
|---|---|
| 遗漏 | 目标总体中的单位不在抽样框 |
| 重复 | 同一单位在抽样框出现多次 |
| 错位 | 抽样框单位与目标总体不对应 |
| 陈旧 | 单位已破产/注销/新增未登记 |

> `Q15-BK-047`：企业破产未注销、新企业未登记 → 抽样框不完整，推断总产值会有偏差。
>
> `Q15-BK-065`：抽样框误差的表现包括遗漏、重复、错位、陈旧等。
>
> `Q17-BK-077`：抽样框误差不会导致估计偏差 → **错**。
>
> `Q17-BK-082`：敲门无人回应 → **无回答误差**，不是抽样框误差。

### 11. 无回答与权数

- 单元无回答：被调查单元没有提供任何信息（`Q16-BK-077`）。
- 项目无回答：某些题项缺失。
- 无回答偏差：回答者与未回答者系统不同。
- 无回答调整因子 = 原样本单元权数之和 / 回答单元权数之和（`Q14-BK-081`）。
- 设计权数 = 入样概率的倒数（`Q14-BK-037`）。
- 所有样本单元设计权数相同 → 自加权抽样设计（`Q14-BK-038`）。

### 12. 样本量

影响因素：

1. 总体变异程度（方差越大，样本量越大）。
2. 估计精度/允许误差（误差越小，样本量越大）。
3. 置信度（置信度越高，样本量越大）。
4. 抽样方法与设计效应。
5. 回答率（回答率越低，初始样本量越大）。
6. 预算、时间、人力。

> `Q13-BK-045 / Q16-BK-048`：计算样本量时两个基本因素是 **总体变异程度** 和 **调查精度要求**。
>
> `Q14-BK-040`：其他条件不变，总体变异程度增加 → 样本量增加。
>
> `Q16-BK-043`：影响样本单位数的主要因素还包括 **置信度/概率保证程度**。
>
> `Q17-BK-081`：甲省人口是乙省 10 倍，样本量不需要也是 10 倍 → 题干错。
>
> `Q13-BK-082`：精度越高，样本量越小 → 错，精度越高样本量越大。
>
> `Q12-BK-043`：回答率偏低时，有效样本数小于精度所需样本数，需要扩大初始样本量。

样本量公式：

- 均值：n0 = (z·σ/E)²；n = n0/(1+n0/N)。
- 比例：n0 = z²·p(1-p)/E²；p 未知取 0.5。
- 考虑设计效应：n = deff·n0。
- 考虑回答率：n_final = n0/回答率。

### 13. 设计效应（deff）

deff = 设计方案的方差 / 简单随机抽样方差。

| deff | 含义 |
|---|---|
| deff = 1 | 与简单随机抽样效率相同 |
| deff < 1 | 效率高于简单随机抽样（如分层抽样） |
| deff > 1 | 效率低于简单随机抽样（如整群抽样） |

> `Q15-BK-041`：deff<1 表示设计方案效率高于简单随机抽样。
>
> `Q16-BK-039`：设计方案效率低于简单随机抽样 → deff>1。
>
> `Q12-BK-047`：样本量相同、deff<1 的抽样方法是分层抽样。
>
> `Q14-BK-069`：分层抽样 deff 通常小于 1；整群抽样通常大于 1；简单随机抽样等于 1。

### 14. 辅助变量、比率估计、回归估计

- 辅助变量：与研究变量相关的已知变量，可用于分层、样本分配、比率/回归估计。
- 辅助变量要求：与研究变量相关，不要求因果；可用于设计阶段和估计阶段。
- 比率估计：R̂ = ȳ/x̄，利用已知总体总量 X 估计 Y。
- 回归估计：ȳ_lr = ȳ + b(X - x̄)。
- 比率估计是回归估计的特例（`Q14-BK-082`）。

> `Q13-BK-047 / Q14-BK-049`：辅助变量不要求与研究变量有因果关系，但要求相关。
>
> `Q13-BK-048 / Q14-BK-050`：抽样设计环节可利用辅助变量进行 **分层**；比率/回归估计属于估计环节。
>
> `Q14-BK-039`：辅助变量与调查变量之间需要存在 **相关关系**。

### 15. 估计量与抽样分布

- 抽样分布：样本估计量的概率分布（`Q13-BK-049`、`Q17-BK-043`）。
- 标准误：估计量的标准差；标准误越小，估计越精确（`Q12-BK-082`）。
- 中心极限定理：大样本下，样本均值近似正态分布。
- 样本估计值与总体真值之差：调查误差/总误差（`Q16-BK-049`、`Q17-BK-049`）。

## 常考结论

1. 抽样误差是随机抽样产生的代表性误差；其他误差都是非抽样误差。
2. 概率抽样可计算抽样误差并推断总体；非概率抽样不能。
3. 总体差异大 → 分层；群内差异大、群间差异小 → 整群。
4. 系统抽样要警惕周期性偏差。
5. 多阶段抽样分阶段抽单元；整群抽样抽中群后调查全部。
6. 二重抽样先大样本筛查，再小样本详查。
7. 样本量取决于变异程度、精度、置信度、设计效应、回答率，不取决于总体规模。
8. 回答率低 → 扩大初始样本量。
9. deff<1 效率高，deff>1 效率低。
10. 辅助变量要求相关，不要求因果。
11. 抽样框误差会造成偏差；无回答是另一种误差。
12. 设计权数是入样概率的倒数。

## 易混点

| A | B | 区别 |
|---|---|---|
| 抽样误差 | 非抽样误差 | 随机抽样代表性误差 vs 其他所有误差 |
| 抽样框 | 抽样单元 | 名录/名单 vs 被抽中的单位 |
| 分层抽样 | 整群抽样 | 层内同质层间异质 vs 群内异质群间同质 |
| 多阶段抽样 | 整群抽样 | 继续抽次级单元 vs 调查群内全部 |
| 二重抽样 | 二阶抽样 | 两次筛选 vs 分阶段抽单位 |
| 重点调查 | 典型调查 | 量上占大头 vs 质上有代表性 |
| 配额抽样 | 分层抽样 | 非随机分配名额 vs 随机分层抽样 |
| 设计权数 | 无回答调整因子 | 入样概率倒数 vs 回答单元权数放大 |
| 抽样误差 | 调查误差 | 抽样误差是总误差的一部分 |

## 答题套路

- 看到“随机抽样产生的代表性误差”→ 抽样误差。
- 看到“回答记录与真值不同”→ 计量误差。
- 看到“名单遗漏/重复/破产未注销”→ 抽样框误差。
- 看到“敲门无人/拒访”→ 无回答误差。
- 看到“总体差异大”→ 分层抽样。
- 看到“群内差异大、群间差异小”→ 整群抽样。
- 看到“每隔固定时间/编号”→ 系统抽样。
- 看到“先大样本筛查，再小样本详查”→ 二重抽样。
- 看到“先抽班级再抽学生”→ 多阶段抽样。
- 看到“网站自愿填答/有奖”→ 自愿抽样。
- 看到“样本量是否随总体规模同比例增加”→ 否。
- 看到“deff<1”→ 效率高；deff>1→ 效率低。

## 待核对

- `Q15-BK-038`：题干“总体变异程度”答案 0.25 是方差口径；若问总体比例，标准答案是 0.5。
- 整群抽样的“群内差异大、群间差异小”是题库/教材口径；部分教材表述为“群内差异小、群间差异大”时指的是分层，注意区分。
- 非概率抽样“能否推断总体”在不同教材中有程度差异：题库口径是“不能用于概率推断”，但探索性研究中仍可提供参考信息。
