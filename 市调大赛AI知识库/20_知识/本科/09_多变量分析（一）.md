# 09 多变量分析（一）

> 对应第17届本科提纲第9章：多变量方差分析、多变量相关与回归分析、分类模型——Logistic 模型。
> 本章题量 27，难度标注为“较难 10%”，重点在“方法适用条件 + 统计量 + 结果解释”。

## 一句话定位

多变量分析（一）处理“一个因变量 + 多个自变量”或“多个因变量 + 分组”的问题：方差分析比较均值，多元回归解释数值因变量，Logistic 回归解释二分类因变量。

## 核心概念

### 1. 方差分析（ANOVA）

- 对象：一个分类自变量（因素）+ 一个数值因变量。
- 目的：检验多个总体均值是否相等。
- 总平方和分解：SST = SSA + SSE。
  - SSA：组间平方和（因素造成的差异）。
  - SSE：组内平方和（随机误差）。
- 自由度：df_T=n-1，df_A=k-1，df_E=n-k。
- 均方：MSA=SSA/(k-1)，MSE=SSE/(n-k)。
- 检验统计量：F=MSA/MSE ~ F(k-1,n-k)。
- 决策：F 大于临界值或 p<α → 拒绝 H0，认为至少有一个总体均值不同。

假定：

1. 独立性：观测值相互独立。
2. 正态性：各水平下总体服从正态分布。
3. 方差齐性：各水平下总体方差相等。

> `Q12-BK-056`：方差分析中，对于因素的每一水平，观测值来自 **同一正态总体**（题库口径）。
>
> `Q12-BK-057`：总离差平方和反映 **全部观测值与总均值的差异**。
>
> `Q13-BK-055 / Q14-BK-055`：MSA/MSE 服从 **F 分布**。
>
> `Q14-BK-053`：单因素方差分析备择假设是 **多个总体均值不全相同**，不是两两都不相同。
>
> `Q14-BK-057`：单因素方差分析涉及一个分类自变量和一个数值因变量。
>
> `Q15-BK-084`：组间方差反映各组均值之间的差异；组内方差反映观测值与组均值的差异。题干说反 → 错。
>
> `Q17-BK-017`：对实验数据进行分析的常用方法是 **方差分析**。
>
> `Q17-BK-072`：F=MSA/MSE，df=(k-1,n-k)。

### 2. 多变量方差分析（MANOVA）

- 对象：一个分类自变量（或多个因素）+ **多个数值因变量**。
- 目的：检验各组在多个因变量上的均值向量是否相等。
- 常用统计量：Wilks' Λ、Pillai's Trace、Hotelling-Lawley Trace、Roy's Largest Root。
- Wilks' Λ：取值 0—1，越小表示组间差异越显著（标准口径）。
- 假定：随机抽样、观测独立、各因变量正态、协方差矩阵齐性、因变量间多元正态。

> `Q13-BK-073`：Wilks Λ 取值 0—1，可用于多变量方差分析显著性检验。题库答案 BCE 中 E“值越大越显著”与标准口径相反，见“待核对”。
>
> `Q14-BK-073`：Wilks 统计量用于单因素多变量方差分析，Wald 统计量用于 Logistic 模型；Wilks 服从 Wilks 分布。
>
> `Q14-BK-056`：组内 df=12，组间 df=5 → 总 df=17。
>
> `Q17-BK-084`：MANOVA 假定包括随机抽样、观测独立、各因变量正态且方差相等、因变量间多元正态。

### 3. 多元线性回归

模型：Y = β0 + β1X1 + β2X2 + … + βkXk + ε。

- 最小二乘估计：使 SSE=Σ(y-ŷ)² 最小。
- 多重判定系数 R²：回归解释的变异比例。
- 调整判定系数：
  R²_adj = 1 - (1-R²)(n-1)/(n-k-1)。
- 回归方程显著性：F=(SSR/k)/(SSE/(n-k-1)) ~ F(k,n-k-1)。
- 单个系数显著性：t=β̂_j/SE(β̂_j)，df=n-k-1。
- 多重共线性：VIF_j=1/(1-R_j²)，R_j² 是 X_j 对其他自变量回归的 R²。
- VIF>10（或>5）通常提示严重共线性。
- 标准化回归系数：比较不同自变量对因变量的相对影响。

> `Q16-BK-056`：R²=0.8，n=100，按 k=5 → R²_adj=1-0.2×99/94≈0.7894。题干未明示 k，见“待核对”。
>
> `Q14-BK-084`：多重判定系数同时考虑样本量和自变量个数 → 错；调整判定系数才考虑。
>
> `Q17-BK-056`：多元回归假定中“随机误差项异方差”是错误说法；应为同方差。
>
> `Q17-BK-057`：偏相关系数是消除其他变量影响后两个变量间的相关系数。
>
> `Q16-BK-084`：VIF 接近 0 表明严重共线性 → 错；VIF 大才是问题。

多元回归假定：

1. 线性：E(Y) 是 X 的线性函数。
2. 误差零均值。
3. 同方差。
4. 误差独立。
5. 误差正态。
6. 自变量间无严重多重共线性。

### 4. Logistic 回归

- 对象：因变量为二分类（0/1）或多分类。
- 模型：logit(p)=ln[p/(1-p)]=β0+β1X1+…+βkXk。
- 概率：p=1/(1+e^(-(β0+ΣβjXj)))。
- 优势（odds）：p/(1-p)。
- 优势比（OR）：e^βj，表示 X_j 增加 1 单位，优势变为原来的 e^βj 倍。
- 估计：最大似然估计（MLE）。
- 检验：
  - 模型整体显著性：似然比检验、Score 检验。
  - 单个系数显著性：Wald 检验。
  - 拟合优度：Hosmer-Lemeshow 检验、-2LL、AIC/BIC。
- 解释：OR>1 增加事件发生优势；OR<1 降低；OR=1 无影响。

> `Q12-BK-084`：Logistic 回归中优势比是事件发生与不发生的概率比，不是不发生与发生之比 → 题干错。
>
> `Q15-BK-057`：Score 检验判断“将自变量纳入 Logistic 模型并进行回归是否有意义”（模型整体显著性）。
>
> `Q14-BK-073`：Wald 统计量用于 Logistic 模型系数显著性。
>
> `Q14-BK-058`：判别分析常与 **聚类分析** 联合使用（先聚类探索分组，再判别分类）。

### 5. 判别分析

- 对象：已知分组 + 多个数值自变量，建立分类规则。
- Fisher 判别：投影到低维，使组间差异最大、组内差异最小；思想基础是方差分析（`Q15-BK-058`）。
- Bayes 判别：基于先验概率和条件概率，最小化误判损失。
- 与聚类区别：判别分析已知分组，聚类分析未知分组。
- 与 Logistic 区别：判别分析假定多元正态、协方差相等；Logistic 对分布假设较少。
- `Q12-BK-058`：判别分析要求分组变量必须是 **定类变量**。
- `Q14-BK-058`：判别分析常与聚类分析联合使用。

### 6. 非参数检验（简介）

- 适用：总体分布未知、样本小、定序数据、违反正态/方差齐性。
- Wilcoxon 符号秩检验：配对样本/单样本，比较中位数。
- Mann-Whitney U 检验：两独立样本。
- Kruskal-Wallis H 检验：多独立样本。
- Mood 方差检验：两样本/多样本的尺度差异。
- 卡方检验：分类变量。

> `Q16-BK-072`：Mood 方差检验用于两样本统计推断，具体表述结合选项。
>
> `Q16-BK-073`：Wilcoxon 符号秩检验对配对差值绝对值编秩，差值为 0 通常不参与编秩。
>
> `Q14-BK-059`：结构方程模型主要处理 **潜变量之间及潜变量与观测变量之间的关系**。

## 常考结论

1. 方差分析：一个分类因素 + 一个数值因变量，F=MSA/MSE。
2. 方差分析备择假设是“均值不全相同”，不是“两两不同”。
3. MANOVA：多个数值因变量，Wilks Λ 取值 0—1。
4. 多元回归：R² 衡量拟合，调整 R² 惩罚变量数。
5. 调整 R² = 1-(1-R²)(n-1)/(n-k-1)。
6. VIF 越大，多重共线性越严重；VIF>10 通常严重。
7. Logistic 回归：logit 变换，OR=e^β，Wald 检验单个系数，Score/似然比检验模型整体。
8. 判别分析已知分组，聚类分析未知分组。
9. Fisher 判别思想基础是方差分析。
10. 非参数检验用于分布未知/小样本/定序数据。

## 易混点

| A | B | 区别 |
|---|---|---|
| 方差分析 | MANOVA | 一个因变量 vs 多个因变量 |
| 方差分析 | 判别分析 | 比较均值 vs 建立分类规则 |
| 判别分析 | 聚类分析 | 已知分组 vs 未知分组 |
| 多元回归 | Logistic 回归 | 数值因变量 vs 二分类因变量 |
| R² | 调整 R² | 未惩罚 vs 惩罚变量数 |
| 多重共线性 | 异方差 | 自变量间相关 vs 误差方差不等 |
| Wald 检验 | Score 检验 | 单个系数显著性 vs 模型整体显著性 |
| Wilks Λ | Wald 统计量 | MANOVA vs Logistic 系数检验 |

## 答题套路

- 看到“多个总体均值是否相等”→ 方差分析。
- 看到“MSA/MSE”→ F 分布。
- 看到“多个因变量”→ MANOVA/Wilks Λ。
- 看到“调整判定系数”→ 1-(1-R²)(n-1)/(n-k-1)。
- 看到“VIF 大”→ 多重共线性。
- 看到“二分类因变量”→ Logistic 回归。
- 看到“优势比/OR”→ e^β。
- 看到“单个系数显著”→ Wald 检验。
- 看到“模型整体显著”→ 似然比/Score 检验。
- 看到“已知分组分类”→ 判别分析；看到“未知分组分类”→ 聚类分析。
- 看到“Fisher 判别思想”→ 方差分析。
- 看到“分布未知/小样本/定序”→ 非参数检验。
